Meet the Altair · Run, stop, continue

Letting the
computer run.

You have been choosing when every instruction happens. Now let the processor keep going. You can stop to look, then continue from exactly where you left it.

Begin here: the countdown from 3 is already loaded. Press RUN, watch A change, then press STOP. The default pace leaves a second between instructions.

The same instructions, without each click.

This is the program from Counting down. Load 3 into A once, then repeat three instructions: subtract one, store A at address 4, and jump back if Z is clear.

We have loaded its eleven bytes for you this time. The reference card lets you examine them. There is no new instruction to learn: RUN simply asks the 8080 to keep taking the same steps.

At the starting pace, the load makes A = 3 after one second. Next comes the subtraction: A = 2, but address 4 still holds 0. The following store writes 2 there. The jump then returns to the subtraction.

Try it. Press RUN, then STOP before the countdown ends. What is the next instruction? Has the latest value in A reached memory yet?

Show an explanation

PC tells you which instruction comes next. After a subtraction, A has changed but the store has not run yet. After a store, A and address 4 agree. The last-instruction explanation tells you what just happened.

Run and stop ↑

Stopping keeps your place.

STOP leaves PC, A, the flags, and memory as they are. Nothing else executes until you ask. Read the state, open the last instruction’s trace, or inspect the recent instruction list.

While stopped, Step one instruction advances just once. RUN continues from the resulting PC. It does not reload the starting count, clear the result, or return to 0100.

The readouts and trace let you inspect without changing anything. The panel’s EXAMINE control has a different purpose: it changes PC, as in the previous lesson. If you EXAMINE another address, RUN will use that new address. Remember the stopped PC if you want to return to it.

Predict it. A holds 2 and PC points to the store at 0105. You press STOP, then RUN. Will A go back to 3?

Show an explanation

No. The next instruction stores 2. Continuing preserves the state that was already there; only executing the load again would read the starting count into A.

Continue from your stopping point ↑

Three different outcomes.

  • You press STOP: execution pauses between instructions. You can continue from the current PC.
  • The countdown reaches its endpoint: A is 0, Z is 1, and the final jump continues to 010B. The lesson stops there automatically.
  • You start the lesson again: the original program and data return, A and the flags are cleared, PC returns to 0100, and the instruction history is emptied.

The countdown takes ten instructions: one load, then three trips through subtract, store, and jump. The final jump still executes even though it does not go backward.

There is no halt instruction in this program. Stopping at 010B is our lesson boundary. To rerun the countdown without clearing anything, EXAMINE 0100 and press RUN. The first load will read the starting count again.

A pace for reading.

Try four instructions per second, then twenty. The program does the same work and reaches the same result. The faster pace makes it harder to follow each change, so STOP and the recent instruction list become useful.

These are teaching speeds. They do not reproduce the Altair’s clock or the different durations of its instructions. The page pauses when hidden and stays stopped when you return.

The memory controls are disabled while running; STOP before using EXAMINE or DEPOSIT. You can still move switches, but their positions alone do not affect execution. Starting again always stops first and keeps your chosen pace and number-guide preference.

A longer experiment

While stopped, EXAMINE address 3, lower all eight data switches, and DEPOSIT 0. Then EXAMINE 0100 and RUN. As in the earlier countdown lesson, subtraction wraps 0 to 255 before counting down. This takes 769 instructions. Try the faster pace, stop partway through, and inspect the recent twelve instructions. The total count keeps increasing even as older entries leave the list.

What this view models

RUN schedules one whole 8080 instruction at a time. STOP takes effect between instructions and does not change the CPU’s stored state. Address and data lamps show PC and RAM at PC at those boundaries. Bus cycles, physical clock timing, and status lamps remain outside this teaching view. As before, the lesson checks the known program bytes and instruction starts before executing.
