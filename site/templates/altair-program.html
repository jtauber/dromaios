Meet the Altair · From switches to instructions

Entering your
first program.

We have supplied every program so far. This time, you will put the bytes into memory yourself, then watch the 8080 carry out the instructions you entered.

Begin here: raise only switch 8 and press EXAMINE to select address 0100. Use the reference card to enter the eight bytes. The walkthrough below takes you from the first deposit to the result.

{{ altair_panel(mode='program') }}

You already know this program.

Read the byte at address 3 into A, add one, then store A at address 4. We used these three instructions in Doing something with a byte. Together they occupy eight bytes.

This lesson starts with 41 at address 3 and zero everywhere else. The program area is empty: neither the reference card nor the step button loads it for you. Switches and DEPOSIT write the same RAM that the processor will read.

The reference card uses hexadecimal for addresses and bytes. 0100 is address 256 in decimal, selected by raising switch 8. Values in A and the two data locations are displayed in decimal.

Eight small deposits.

  1. Raise only switch 8 and press EXAMINE. The address lights show 0100.
  2. Prepare 3A, binary 00111010, in the lower eight switches: raise 5, 4, 3, and 1, and lower the others in that group. Press DEPOSIT.
  3. Prepare 03 by raising only 1 and 0 in the lower group. Press DEPOSIT NEXT. It moves to 0101 before writing.
  4. Continue with 00 C6 01 32 04 00, using DEPOSIT NEXT once for each byte. The reference card shows each destination and the byte stored there.

The higher switches can stay where they are during deposits: only the lower eight supply the byte. When preparing a new byte, change the switches that differ and leave the others alone.

Before the first deposit: will preparing 3A change the selected address?

Show an explanation

No. Moving switches only prepares a value. DEPOSIT writes it at the selected address, 0100. EXAMINE would instead select the address in all sixteen switches, so keep the two actions distinct.

Enter the bytes ↑

Read them back.

Raise only switch 8 again and press EXAMINE. Read 3A at 0100, then use EXAMINE NEXT seven times. The data lights should show 03 00 C6 01 32 04 00 in order.

If a byte differs, leave that address selected, prepare the correct byte, and DEPOSIT. You can repair one location without starting over.

The added reference card helps you check your work. A zero that was already in RAM counts as a match; it does not prove you deposited anything. At 0104, any byte is valid because it supplies the amount to add. Choose 01 for this first run.

Now let the processor read.

Raise only switch 8 and EXAMINE 0100 once more. In this lesson the selected address is connected to the processor’s PC. You have chosen where execution will begin.

Under the panel, press Step one instruction three times, pausing to predict each change:

  1. The 8080 fetches 3A 03 00, then reads address 3. A becomes 41 and PC advances to 0103.
  2. It fetches C6 01 and adds one. A becomes 42, memory stays unchanged, and PC advances to 0105.
  3. It fetches 32 04 00 and writes A to address 4. That location now holds 42, and PC reaches 0108.

Those are the bytes you entered. Open “Look inside the last instruction” to see what the CPU fetched and which memory locations it accessed.

The address lights follow PC after each instruction. To see the result on the data lights, EXAMINE address 4. A remains 42: inspecting memory changes PC, but preserves A and the flags.

Why stop at 0108?

Show an explanation

That is the end of our three-instruction exercise. The lesson stops offering steps there; we have not entered a halt instruction. A real machine could continue into the following bytes.

Execute your program ↑

Change the program you entered.

EXAMINE 0104 by raising only switches 8 and 2. Prepare 02 in the lower eight switches, then DEPOSIT. You have changed the addition’s operand.

EXAMINE 0100 again and step three times. The load still reads 41, but the addition now produces 43, which the store writes to address 4.

Returning to 0100 does not reset the processor or erase RAM. “Start this lesson again” does: it clears the program and restores the initial data. Use EXAMINE when you want to rerun what you entered.

What this view models

The original Altair’s EXAMINE circuitry made the 8080 jump to the switch address; EXAMINE NEXT advanced it. Here we apply those PC changes directly, preserving other CPU state. Program instructions execute on our 8080 model. The lights show PC and RAM at PC between instructions, rather than every bus transfer. The added step control runs a whole instruction; the hardware SINGLE STEP control advanced one machine cycle. RUN, STOP, timing, and status lamps remain outside this lesson.

For this exercise, the step control requires the reference bytes except the editable operand, and PC at one of the three instruction starts. This teaching guard catches entry mistakes before execution. The original Altair allowed arbitrary programs.

The panel–CPU connection follows the MITS Altair 8800 Theory of Operation, pp. 5–6.
