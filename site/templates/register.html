A copy in A.

Press Read address 3 into A. A now holds 200, and address 3 still holds 200. Reading a byte does not take it away from memory.

The processor has copied the value into a separate place. A is a register inside the processor; it is not another address in this RAM.

Try it. After reading, change the byte at address 3 to 17. What happens to A?

Show an explanation

A still holds 200. It received a copy of the earlier value. Editing memory does not update that copy.

A copy back to memory.

Now press Write A to address 4. The value in A replaces whatever was at address 4. A itself keeps its value.

If you changed address 3 to 17 after reading, address 4 still receives 200. The write takes its value from A, not from address 3.

Predict it. Start again. Change address 3 to 255 before reading it. After both instructions, what will be in A, address 3, and address 4?

Show an explanation

All three will hold 255. They are three independent copies: changing either memory location afterward leaves the other location and A unchanged.

Load, then store.

Bringing a value into a register is called a load. Writing it from a register to memory is called a store.

On the Intel 8080, A is also called the accumulator. It is a working register used for arithmetic. Soon we will change its value with a calculation between the load and the store.

For now, the important idea is that a register can hold a copy of a byte independently of memory. Each button above runs a real 8080 instruction to make that copy.
