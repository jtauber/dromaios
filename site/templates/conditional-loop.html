Memory and the processor · A conditional jump

Knowing
when to stop.

Our last loop always went around again. This time, the processor uses the carry flag to choose: repeat the addition, or leave the loop.

One new instruction.

We still load, add one, and store. The starting byte is now 254, so we can reach wraparound quickly.

The last instruction is JNC 0103H: jump if no carry. “No carry” means CY = 0, also called clear. CY = 1 is called set.

  • CY = 0: jump back to the addition at 0103.
  • CY = 1: continue after the jump, at 010B.

This is a conditional jump: whether it jumps depends on a condition. The processor reads the flag when it executes the instruction.

Predict it. Take three steps: load 254, add one, and store. A and address 4 now hold 255. What is CY? Where will the jump go?

Show an explanation

254 + 1 fits in a byte, so CY = 0. The store preserves that flag. JNC will take the backward jump to 0103.

Try the first decision ↑

The same jump, a different decision.

Take the jump, then add again. 255 + 1 gives A = 0 and sets CY = 1. The store writes 0 to address 4 and leaves CY set.

Predict it. PC is back at 0108. The jump’s bytes are unchanged. Will it return to the addition this time?

Show an explanation

No. CY = 1, so the “no carry” condition is false. JNC still runs and fetches its three bytes, but it leaves PC at 010B, immediately after them. This is called falling through.

Follow the second decision ↑

Watch the last-instruction explanation: it reports the carry value the jump inspected and the PC transition it produced. The jump runs twice, even though only the first execution jumps backward.

A flag remembers a result.

The addition sets carry. The store preserves it. The jump reads it. The jump does not redo the addition or inspect the byte at address 4.

Try it. Start again and step until the second store has written 0. Before the jump, change address 4 to 99. Will that make the loop repeat?

Show an explanation

No. Editing memory does not change CY. It is still 1, so JNC falls through. Address 4 keeps your 99 because the program does not reach another store.

Change memory before the decision ↑

You can also change address 3 before the load. Try 255 for one trip through the loop, or 253 for three. Changing that source after the load leaves A and the remaining work unchanged.

Leaving the loop.

At 010B, this lesson stops offering steps. The processor has left the loop; it has not executed a halt instruction. A larger program could put more instructions at that address.

Each press still runs exactly one instruction. The jump chooses the next address, while you choose when the processor takes its next step.

We can now connect a calculation to a decision: an instruction changes a flag, and a later instruction uses that flag to choose a path.
