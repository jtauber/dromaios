      About device activity
      Captured accesses from completed CPU instructions in $C000–CFFF, including slot ROM and unmapped addresses. Newest first; identical consecutive accesses from the same instruction are grouped, retaining their count. Keeps the latest 128 groups, even with Live off or this panel hidden. Clear keeps instruction numbering; reset, fresh power-on, restore, media replacement and register/RAM edits start new history.
      Instruction links browse current Disassembly only if the observed mapping is still visible; code bytes may have changed. Address links open Memory, and descriptions link to the specification. Descriptions explain the declared operation; the displayed byte is the actual transferred value. Host keyboard delivery is separate and has no responsible CPU instruction. No device reads are performed by this view.
