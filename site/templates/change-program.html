Before stepping, change Add this number to A from 1 to 2. Look at address 0104 in the program view: it now holds 02. The addition’s bytes are C6 02.

You have edited memory. A is still 0, the starting data is still 41, and PC still points to 0100. Nothing has run yet.

Predict it. Step through the three instructions. What will A hold after each step? What will be written to address 4?

The load puts 41 into A. The addition makes it 43. The store writes 43 to address 4 and leaves A at 43. Carry stays 0.

The field locks when you take the first step, so this run uses the program you chose. Start again restores all the original values, including the addition’s 01, and lets you choose another number. This editing rule belongs to the lesson; the RAM itself is writable.

What to do, and what to use.

The two bytes play different roles. C6 selects the operation: add a number to A. We call this the opcode. The following byte supplies the number to add: the operand.

The operand is part of the instruction itself. This is called immediate addressing, which is where the I in the 8080 name ADI comes from: add immediate.

The field accepts decimal numbers from 0 to 255. The program view shows hexadecimal bytes, while labels such as ADI 2 use decimal. Try entering 10: the bytes become C6 0A. These are two ways of writing the same operand.

This experiment lets you change only that operand. The opcode and the load/store addresses stay fixed, so the program always reads address 3, adds your number, and writes to address 4.

Same path, new result.

Changing the operand changes the calculation, but the addition still occupies two bytes. PC follows the same path: 0100 → 0103 → 0105 → 0108.

Try zero. Start again and choose 0. Does the processor skip the addition?

Show an explanation

No. It still fetches C6 00 and executes the addition. A remains 41, but PC advances to 0105. The addition also updates the arithmetic flags, even though A’s value is unchanged.

Try a larger number. Start again and choose 255, shown as FF in the program. What happens to 41 + 255?

Show an explanation

The full sum is 296. A holds 40, the rightmost eight bits, and CY becomes 1. The store writes 40 to address 4. PC still follows the same path.

Try adding 255 ↑

Two kinds of edit.

Changing address 3 gives the same program different starting data. Changing 0104 changes a number inside the program. Both edits write a byte into the same RAM; its role depends on how the processor uses it.

You have changed a program by changing its bytes. So far, each instruction still leads to the next one in memory. A different kind of instruction—a jump—will let us change that path too.
