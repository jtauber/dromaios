No disk mounted

35-track, single-sided disks (161,280 bytes). Loaded disks start read-only. Pause while idle to make a writable copy or exchange disks; your original file is unchanged. Export downloads the current bytes. Fresh power-on and snapshots retain the disk and write permission.

Enter 10 PRINT 42, then SAVE "ANSWER". Export when SAVE finishes. Reload the exported disk after fresh power-on, then LOAD and RUN. A paused transfer can also be saved in Snapshot or exported with only the bytes written so far.

Load Color BASIC, Extended BASIC, and Disk BASIC in ROM, then Run. Type DIR to list files, LOAD "ANSWER", then RUN for the example disk.

No tape mounted

Run advances the computer; the running program controls the tape motor. In BASIC, Record then CSAVE "DOT"; Rewind and Play then CLOAD "DOT". Cartridges use their own save and load commands.

Pause to load, replace, or export. Record overwrites from the current position. New blank replaces the mounted tape. Load ordinary CoCo CAS files or mono 8-bit PCM WAV at 44,100 Hz, up to two minutes. Export always produces WAV. Files stay on this device.

Keyboard and execution
        
Sound enables clocked audio during Normal Run. Try SOUND 128,2 in Color BASIC, or PLAY "T4O3L8V15CEGP8V7C" with Extended BASIC. Pause and Unlimited are silent.

        
Click the screen to type or paste one line. Enter submits; Backspace edits; Escape or Ctrl-C sends Break; Home sends Clear. Host key repeat is ignored. Leaving the window pauses and releases queued keys.

        
Reset CPU preserves RAM and device settings. Fresh power-on clears them, keeps the installed ROMs, and leaves the mounted tape stopped at its current position. Normal targets the declared CPU clock rate; Unlimited runs as fast as the browser allows. Clocks include waiting time. Mark clock measures an interval; Step, Step over, and Step out report their clocks separately.

        
Run to address executes normally and pauses before the next boundary at that PC, or after 2,000,000 boundaries. Breakpoints and RAM write watchpoints can stop it earlier. Run, Step, Pause, reset, and leaving the window cancel the target.
