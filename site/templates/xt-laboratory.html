Following calls
Step over runs through a near call, far call, or interrupt and stops at its matching return. On other instructions it advances one boundary. Step out returns from the innermost observed call or interrupt. Breakpoints and RAM watches still stop execution; each request has a two-million-boundary limit.

        
Call stack shows observed CS:IP pairs and the caller’s SS:SP. Select an address to browse Disassembly. Reset and restore clear this history; changing the stack or returning elsewhere invalidates it.

      
Using the keyboard
At BASIC’s Ok prompt, type PRINT 2+3 and press Enter. You can paste several lines at once. Ctrl-Break interrupts a running BASIC program. Ctrl-Alt-Del sends the XT restart chord.

      
Speed, clocks and sound
Normal follows the XT’s 14,318,180 Hz oscillator; Unlimited runs as fast as the browser allows. Mark clock measures elapsed ticks, including DMA and halted time. Step, Step over and Step out report their intervals separately. CPU reset preserves time; power-on and checkpoint restore clear the marker.

        
Sound plays the PC speaker during Normal Run. Try BEEP or SOUND 440,9 at BASIC’s Ok prompt. Pause and Unlimited are silent; restoring a checkpoint resumes the saved timer phase with a fresh audio queue.

Reading the trace
Newest first. IN and OUT show each captured byte transfer; INTA shows the acknowledged vector. Entry and IRET link to their destinations. DMA2 links each transferred byte to RAM and names its disk-image offset. DMA runs before the CPU boundary, not as an instruction store; refresh grants are omitted. Times are oscillator ticks at the end of the complete CPU/board boundary, not individual bus-cycle timings. Record is independent of Live updates.

        
Reset and restore clear this history. Only completed boundaries are recorded; an execution error may leave partial effects outside the trace.

Requests and service
Pending requests survive masking. The highlighted row is the controller’s selected request; CPU IF and recognition delays still govern acceptance. Acknowledge moves a request into service. The BIOS clears the keyboard receiver through port 61, then sends EOI to port 20; IRET separately restores CPU state.

    

    

      

        
        
        
      

      

        

        

        

        
Reading sector activity
Newest commands first. Byte spans link to RAM; image offsets use the mounted 360 KiB geometry. TC ends DMA; the controller result and IRQ6 entry are separate observations. A normal result may name the next sector ID. Continued entries begin after recording starts or a checkpoint is restored, so their byte totals cover only the observed suffix. Reset, restore and media exchange clear this history. Live affects drawing; Record controls capture independently of Port trace.

      

      

        

        

        

        
Recorded transfers

        
Reading file allocation
Read-only, paused inspection of this mounted 360 KiB FAT12 disk. Sector numbers start at zero. Short root names, volume labels and subdirectory allocations are shown; subdirectory contents and long names are not decoded. Non-ASCII name bytes appear as hex escapes. Invalid chains and mismatching FAT copies are reported.
File ranges exclude trailing slack from RAM links. FAT entries share packed bytes with their neighbours. Links match this snapshot's allocation against retained activity; they do not prove past file ownership or that RAM still contains those bytes. DOS may cache reads. A mid-write snapshot may contain incomplete filesystem updates.

Following a sector read
Choose the BIOS sector read walkthrough. Channel 2's address points to the next RAM byte. Its count is bytes remaining minus one; FFFF after terminal count is the wrapped counter. DMA “write” means a write to memory. Completion raises IRQ6; reading the controller's result, sending PIC EOI, and returning from the BIOS are separate events. Inspection never consumes a status or result register.

Previewed storage accesses
A private copy predicts the next boundary. Port I/O, TEST, and coprocessor connections stop the preview.

Add a debugger stop for the selected service's AH, for any caller or handle. Returns and errors require an observed call; only services with a declared carry-error result offer error stops.

        
DOS interpretation of INT 21h. Retains 128 calls and samples up to 256 bytes from declared storage. Input samples are captured at interrupt entry; output samples at the observed return. Memory links browse current storage. Reset and checkpoint restore clear this history; a return without a captured call is not interpreted.
