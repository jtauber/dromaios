{% if mode == 'buffer' %}

This lesson connects an 8080, 65,536 bytes of RAM, and separate teaching input and output devices. The program collects up to eight characters, appends NUL, prints the buffer, and halts. Start again restores the program, clears RAM, registers, flags, halted state, both devices, output, counts, and history, prepares H, and stops at PC 0000. It is not the hardware RESET switch.

{% elif mode == 'terminated-message' %}

This lesson connects an 8080, 65,536 bytes of RAM, and a teaching output device at port 1. The program at 0000 reads text at 0100 until it finds zero. Start again restores the program and data, clears registers, flags, halted state, output, counts, and history, and stops at PC 0000. It is not the hardware RESET switch.

{% elif mode == 'message' %}

This lesson uses the existing 8080 HELLO example: a program at 0000, message bytes at 0100, and the same teaching output device at port 1. Start again restores the program and message, clears the registers, flags, halted state, output, counts, and history, and stops at PC 0000. It is not the hardware RESET switch.

{% elif mode == 'reply' %}

This teaching terminal adds a comparison, a conditional jump, and a replacement instruction to the polling program. Start again restores the program, empties both devices and the text display, clears counts and history, prepares lowercase a, and stops at PC 0100. It is not the hardware RESET switch or a model of a particular historical terminal.

{% elif mode == 'terminal' %}

This teaching terminal uses the same polling program, input latch, and output port as the lamp lesson. Start again restores the program, empties both devices and the text display, clears counts and history, prepares A, and stops at PC 0100. It is not the hardware RESET switch or a model of a particular historical terminal.

{% elif mode == 'polling' %}

This lesson connects an 8080, 65,536 bytes of RAM, input readiness at port 0, input data at port 1, and a separate output device at port 1. The program keeps looping until you STOP; it has no final instruction. Start again restores the program, empties both devices, clears counts and history, prepares 42, and stops at PC 0100. It is not the hardware RESET switch.

{% elif mode == 'input' %}

This lesson connects an 8080, 65,536 bytes of RAM, and separate teaching devices at input and output port 1. Start again restores the loaded program, empties both devices, clears the counts and history, prepares 42 on the input switches, and stops at PC 0100. It is not the hardware RESET switch.

{% elif mode == 'output' %}

This lesson connects an 8080, 65,536 bytes of RAM, and an eight-lamp teaching device at output port 1. The device is an added illustration, not a built-in Altair display. Start again restores the loaded program and initial data, empties the device, clears both counts and history, and stops at PC 0100. It is not the hardware RESET switch.

{% elif mode == 'running' %}

This lesson supplies an 8080, 65,536 bytes of RAM, and the loaded countdown. The lights show PC and RAM at PC between instructions; bus cycles and status lamps are not modeled. Start again restores the program and initial data, clears execution history, and stops. It is not the hardware RESET switch.

{% elif program %}

This lesson connects the panel to an 8080 and 65,536 bytes of RAM. The lights show PC and RAM at PC between instructions; bus cycles and status lamps are not modeled. Start again clears the program, restores 41 at address 3, and starts A and PC at zero. It is not the hardware RESET switch.

{% else %}

A focused model of the Altair’s memory controls. This lesson provides RAM at all 65,536 addresses and performs no CPU execution. Start again clears our experiment; it is not the hardware RESET switch.

{% endif %}
