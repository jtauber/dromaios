# Intel 8259A: the XT's interrupt controller

The 8259A collects eight interrupt requests, chooses a priority, and supplies
an interrupt vector when the CPU acknowledges. It does not execute the handler
or own the CPU's interrupt-enable flag. The XT connects the timer to IR0 and
keyboard to IR1. [Intel's datasheet][manual], pages 7–17, defines the command
words and priority rules; [IBM's BIOS listing][ibm], A-9, supplies the XT's
initialization sequence: `13` at port `20`, then `08`, `09`, `FF` at port `21`.

This profile implements **single-controller, edge-triggered, 8086/8088 mode**,
fixed fully nested priority (IR0 highest), ordinary EOI, and IRR/ISR selection.
The buffered-mode bits are accepted; external bus-driver signals are not
simulated. Cascading, level triggering, automatic EOI, rotation, polling, and
special mask/nested modes are rejected before changing state. Acknowledge is
one atomic event rather than two timed INTA bus cycles. Electrical pulse-width
qualification and races between those cycles remain outside this profile.

## Requests, service, and initialization

IRR retains pending edges, IMR masks delivery, and ISR records handlers in
service. Masking does not discard a pending request. External input levels are
stored separately so repeated sampling of a held line cannot manufacture edges.
PHASE is 0 before initialization, 1 awaiting ICW2, 2 awaiting ICW4, or 3 ready.
ICW3 is absent in a single-controller system.

```device
device "i8259a"

state {
  register IRR: 8
  register ISR: 8
  register IMR: 8
  register BASE: 8
  register LEVELS: 8
  register PHASE: 3
  latch READ_ISR
}

action resetController "Return to the deterministic uninitialized model state" {
  IRR <- u8(0)
  ISR <- u8(0)
  IMR <- u8($FF)
  BASE <- u8(0)
  PHASE <- u3(0)
  READ_ISR <- 0
}

action initialize "Begin with disconnected interrupt lines low" {
  perform resetController()
  LEVELS <- u8(0)
}

source ready "The complete initialization sequence has been received" : flag {
  phase = register PHASE
  return equal(phase, u3(3))
}

source lowestBit "Isolate the highest-priority set request, or zero" (mask: 8): 8 {
  return and(mask, subtract(u8(0), mask))
}

source pending "Select one unmasked request above every in-service priority" : 8 {
  requests = register IRR
  service = register ISR
  masked = register IMR
  enabled = source ready()
  first = source lowestBit(service)
  // With no ISR bit, 00 - 1 wraps to FF and admits all priorities.
  above = subtract(first, u8(1))
  eligible = and(and(requests, xor(masked, u8($FF))), above)
  selected = source lowestBit(eligible)
  return select(enabled, selected, u8(0))
}

source irq "INT is asserted when a request can be serviced" : flag {
  selected = source pending()
  return not(zero(selected))
}

source vector "Inspect the selected vector, with level 7 for a spurious acknowledge" : 8 {
  base = register BASE
  selected = source pending()
  // Encode a one-hot request as the three low vector bits.
  bit2: flag = not(zero(and(selected, u8($F0))))
  bit1: flag = not(zero(and(selected, u8($CC))))
  bit0: flag = not(zero(and(selected, u8($AA))))
  level = pack<8>(0, 0, 0, 0, 0, bit2, bit1, bit0)
  return or(base, select(zero(selected), u8(7), level))
}

action acknowledge "Move only the accepted request from IRR to ISR" {
  selected = source pending()
  requests = register IRR
  service = register ISR
  IRR <- and(requests, xor(selected, u8($FF)))
  ISR <- or(service, selected)
}

source lineMask "One bit for an interrupt input" (line: 3): 8 {
  mask = iterate(extend(line, 8), u8(1)) {
    return shiftLeft(mask, 0)
  }
  return mask
}

action setLine "Sample a settled external interrupt level" (line: 3, high: flag) {
  mask = source lineMask(line)
  levels = register LEVELS
  requests = register IRR
  enabled = source ready()
  rising: flag = and(high, zero(and(levels, mask)))
  when and(enabled, rising) {
    IRR <- or(requests, mask)
  }
  LEVELS <- or(and(levels, xor(mask, u8($FF))), select(high, mask, u8(0)))
}
```

The board reads `vector()` and calls `acknowledge()` inside the CPU's accepted
INTR callback. A masked or deferred CPU interrupt must never call that callback.
Acknowledge with no eligible request leaves ISR unchanged and returns the
level-7 vector through `vector()`. Holding an input high cannot retrigger it;
a subsequent low/high transition can queue a new request even during service.
Input changes before initialization completes establish levels but no requests.

## Command words

ICW1 clears request/service/mask state and selects IRR readback. It preserves
the sampled pin levels: a held input must fall and rise after initialization.
The byte fields used only in MCS-80 mode are ignored. ICW2 supplies the upper
five vector bits. ICW4 must select 8086 mode without automatic EOI or special
fully nested mode; the ordinary buffered and unbuffered forms are supported.

```device
source status "Read the selected request or in-service register" : 8 {
  requests = register IRR
  service = register ISR
  readService = latch READ_ISR
  return select(readService, service, requests)
}

source mask "Inspect the interrupt mask" : 8 {
  value = register IMR
  return value
}

source writeCommand "Initialize or apply a supported operation command" (byte: 8): flag {
  accepted = choose bit(byte, 4) : flag {
    then {
      supported: flag = equal(and(byte, u8($1B)), u8($13))
      when supported {
        perform resetController()
        IMR <- u8(0)
        PHASE <- u3(1)
      }
      return supported
    }
    else {
      initialized = source ready()
      command = and(byte, u8($F8))
      statusCommand: flag = equal(and(byte, u8($FC)), u8($08))
      eoi: flag = or(equal(command, u8($20)), equal(command, u8($60)))
      noOperation: flag = or(equal(command, u8($00)), equal(command, u8($40)))
      supported: flag = and(initialized, or(statusCommand, or(eoi, noOperation)))
      when supported {
        when and(statusCommand, bit(byte, 1)) {
          READ_ISR <- bit(byte, 0)
        }
        when eoi {
          service = register ISR
          first = source lowestBit(service)
          specified = source lineMask(bits(byte, 2, 0))
          cleared = select(bit(byte, 6), specified, first)
          ISR <- and(service, xor(cleared, u8($FF)))
        }
      }
      return supported
    }
  }
  return accepted
}

source writeData "Receive ICW2, ICW4, or an ordinary mask" (byte: 8): flag {
  phase = register PHASE
  icw4: flag = and(equal(phase, u3(2)), equal(and(byte, u8($F3)), u8(1)))
  supported: flag = or(equal(phase, u3(1)), or(equal(phase, u3(3)), icw4))
  when supported {
    when equal(phase, u3(1)) {
      BASE <- and(byte, u8($F8))
      PHASE <- u3(2)
    }
    when equal(phase, u3(2)) {
      PHASE <- u3(3)
    }
    when equal(phase, u3(3)) {
      IMR <- byte
    }
  }
  return supported
}

source validState "Restore only aligned vectors and reachable initialization phases" : flag {
  base = register BASE
  phase = register PHASE
  requests = register IRR
  service = register ISR
  validPhase: flag = lessThan(phase, u3(4), unsigned)
  active: flag = or(equal(phase, u3(3)), zero(or(requests, service)))
  return and(zero(and(base, u8(7))), and(validPhase, active))
}

interface I8259a {
  size 2
  initialize initialize
  reset resetController
  validate validState
  input setLine
  input acknowledge
  view ready
  view irq
  view vector
  read 0 status
  read 1 mask
  write 0 writeCommand
  write 1 writeData
}
```

OCW2 supports non-specific EOI (`20`), specific EOI (`60–67`), and the
non-rotating no-operation forms. OCW3 `0A/0B` selects IRR/ISR; `08/09` preserves
the current selection. Reading registers never acknowledges a request.
The model's `reset()` is a host lifecycle operation, not an 8259A reset pin:
the physical chip is initialized by ICW1. It preserves external input levels.
Snapshots own all registers and levels, including partially completed ICWs.
