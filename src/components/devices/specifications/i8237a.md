# Intel 8237A: DMA registers and single transfers

The 8237A temporarily takes the address bus from the CPU. Each of its four
channels holds an address, a remaining word count, and a transfer mode. In the
XT, channel 0 refreshes dynamic RAM; the other channels serve expansion devices.
A DMA **read** means memory-to-device, a **write** means device-to-memory, and a
**verify** advances the counters without asserting either data-transfer command.
These names describe the memory operation, not the CPU's view of an I/O port.

[Intel's datasheet][intel], pages 4–9, defines these registers and transactions.
This profile implements all four address/count register pairs, fixed priority,
active-high requests, and single read/write/verify transfer accounting with
optional decrement and automatic reload. It rejects demand, block, cascade, memory-to-memory,
software-request assertion, compressed timing, rotation, and altered
pin polarities. The XT's BIOS uses single read for refresh and single verify
for its initially masked peripheral channels. Supporting their register setup
is not a claim that floppy or other peripheral DMA is implemented. Diskette
reads also program a single DMA write; the empty-drive profile accepts that
setup but never asserts DREQ2 or transfers a byte.

The generated device owns register behavior. A board observes `pending()`,
`transferReady()`, `transferChannel()`, `transferAddress()`, `readTransfer()`, and
`writeTransfer()`, performs the declared bus operation, then calls `completeTransfer()`. There are
no implicit memory callbacks, elapsed clocks, or CPU instructions in this chip.
The [XT refresh example](../../../machines/8088/xt-refresh.md) supplies its timing
and wiring. Individual S-states, READY waits, external EOP, and overlapping
programming/active cycles remain outside this atomic transfer model.

## Channel registers and the shared byte selector

ADDRESS and COUNT are the current registers. BASE_ADDRESS and BASE_COUNT retain
the programmed reload values and cannot be read through the guest ports. Each
byte write updates the corresponding byte in **both** base and current storage;
it does not replace the other byte. The single HIGH_BYTE flip-flop alternates
on every address/count read or write, even when successive accesses use different
channels or directions. Writing port `0C` selects the low byte again.

```device
device "i8237a"

state {
  array ADDRESS: 16[4]
  array COUNT: 16[4]
  array BASE_ADDRESS: 16[4]
  array BASE_COUNT: 16[4]
  array MODE: 8[4]
  register COMMAND: 8
  register MASK: 8
  register LEVELS: 8
  register TERMINAL: 8
  latch HIGH_BYTE
}

action resetController "Disable all channels without changing their address, count, mode, or external pins" {
  COMMAND <- u8(0)
  MASK <- u8($0F)
  TERMINAL <- u8(0)
  HIGH_BYTE <- 0
}

action initialize "Choose deterministic power-on values for otherwise unspecified channel registers" {
  perform resetController()
  ADDRESS[] <- u16(0)
  COUNT[] <- u16(0)
  BASE_ADDRESS[] <- u16(0)
  BASE_COUNT[] <- u16(0)
  MODE[] <- u8(0)
  LEVELS <- u8(0)
}

source replaceByte "Replace the byte selected by the common flip-flop" (word: 16, byte: 8): 16 {
  high = latch HIGH_BYTE
  return select(high, withBits(word, 15, 8, byte), withBits(word, 7, 0, byte))
}

source readWord "Read one current register byte and advance the shared byte selector" (channel: 3, count: flag): 8 {
  address = array ADDRESS[and(channel, u3(3))]
  remaining = array COUNT[and(channel, u3(3))]
  high = latch HIGH_BYTE
  word = select(count, remaining, address)
  HIGH_BYTE <- not(high)
  return select(high, highByte(word), lowByte(word))
}

action writeWord "Write matching bytes in base and current registers" (channel: 3, count: flag, byte: 8) {
  when count {
    current = array COUNT[and(channel, u3(3))]
    base = array BASE_COUNT[and(channel, u3(3))]
    currentByte = source replaceByte(current, byte)
    baseByte = source replaceByte(base, byte)
    COUNT[and(channel, u3(3))] <- currentByte
    BASE_COUNT[and(channel, u3(3))] <- baseByte
  }
  when not(count) {
    current = array ADDRESS[and(channel, u3(3))]
    base = array BASE_ADDRESS[and(channel, u3(3))]
    currentByte = source replaceByte(current, byte)
    baseByte = source replaceByte(base, byte)
    ADDRESS[and(channel, u3(3))] <- currentByte
    BASE_ADDRESS[and(channel, u3(3))] <- baseByte
  }
  high = latch HIGH_BYTE
  HIGH_BYTE <- not(high)
}
```

Reset and software master clear preserve the channel registers and mode words;
they clear command, terminal status, and the byte selector, and set all masks.
Fresh construction alone chooses zero for the unspecified channel contents.
The temporary register always reads zero because memory-to-memory transfers
are excluded. Software request bits stay clear: clearing one is accepted,
setting one is rejected because Intel requires block mode for software requests.
External request pins are not reset by a programming command.

## Requests, priority, and terminal count

Status bits 7–4 report request levels even when masked or controller-disabled.
Bits 3–0 remember terminal count and clear on a status read; inspection views
and snapshots leave them intact. Fixed priority selects channel 0 before 1,
then 2, then 3. Masking or disabling inhibits service without erasing the pins.

A count of N requests **N+1 transfers**. After each transfer the address changes
by one and COUNT decrements. A transition from zero to `FFFF` sets terminal
status. Automatic initialization reloads both base registers; without it,
terminal count masks the channel. The external request is released by the
connected device, not by the DMA counter. A held request may therefore ask for
another single transfer after the CPU has had a turn on the bus.

```device
action setRequests "Sample the four active-high DREQ pins" (dreq0: flag, dreq1: flag, dreq2: flag, dreq3: flag) {
  LEVELS <- pack<8>(0, 0, 0, 0, dreq3, dreq2, dreq1, dreq0)
}

source pending "Select the highest-priority unmasked request as a one-hot bit" : 8 {
  levels = register LEVELS
  masked = register MASK
  command = register COMMAND
  eligible = and(levels, xor(masked, u8($0F)))
  first = and(eligible, subtract(u8(0), eligible))
  return select(bit(command, 2), u8(0), first)
}

source transferChannel "Encode the selected channel; zero when no request is pending" : 3 {
  selected = source pending()
  return pack<3>(0, not(zero(and(selected, u8($0C)))), not(zero(and(selected, u8($0A)))))
}

source transferReady "Require a pending request and a programmed single-transfer mode" : flag {
  selected = source pending()
  channel = source transferChannel()
  mode = array MODE[and(channel, u3(3))]
  return and(not(zero(selected)), bit(mode, 6))
}

source transferAddress "Observe the selected channel's current address" : 16 {
  channel = source transferChannel()
  address = array ADDRESS[and(channel, u3(3))]
  return address
}

source readTransfer "Distinguish a memory read from a write or verify transfer" : flag {
  channel = source transferChannel()
  mode = array MODE[and(channel, u3(3))]
  return bit(mode, 3)
}

source writeTransfer "Distinguish a memory write from a read or verify transfer" : flag {
  channel = source transferChannel()
  mode = array MODE[and(channel, u3(3))]
  return bit(mode, 2)
}

action completeTransfer "Account for one completed single transfer; idle and unconfigured calls do nothing" {
  ready = source transferReady()
  when ready {
    selected = source pending()
    channel = source transferChannel()
    address = array ADDRESS[and(channel, u3(3))]
    count = array COUNT[and(channel, u3(3))]
    mode = array MODE[and(channel, u3(3))]
    baseAddress = array BASE_ADDRESS[and(channel, u3(3))]
    baseCount = array BASE_COUNT[and(channel, u3(3))]
    terminal: flag = zero(count)
    reload: flag = and(terminal, bit(mode, 4))
    nextAddress = select(bit(mode, 5), subtract(address, u16(1)), add(address, u16(1)))
    ADDRESS[and(channel, u3(3))] <- select(reload, baseAddress, nextAddress)
    COUNT[and(channel, u3(3))] <- select(reload, baseCount, subtract(count, u16(1)))
    when terminal {
      oldTerminal = register TERMINAL
      TERMINAL <- or(oldTerminal, selected)
      when not(reload) {
        masked = register MASK
        MASK <- or(masked, selected)
      }
    }
  }
}

source status "Read pending and terminal flags, clearing only the terminal flags" : 8 {
  levels = register LEVELS
  terminal = register TERMINAL
  TERMINAL <- u8(0)
  return or(shiftBits(levels, left, 4), terminal)
}

source temporary "Memory-to-memory operation is excluded, so the temporary register stays clear" : 8 {
  return u8(0)
}
```

## Programming ports

Ports `00–07` alternate address/count for channels 0–3. Port `08` writes the
command register or reads status; `09` changes software requests; `0A` changes
one mask bit; `0B` sets a channel's mode; `0C` clears the shared byte selector;
`0D` master-clears on write and reads the temporary register; `0E` clears all
masks; and `0F` writes all masks. Reads of `09–0C` and `0E–0F` are unbound,
matching Intel's illegal-read entries rather than inventing mask readback.
Reserved/don't-care bits in request/mask commands are ignored. Unsupported
command or mode writes reject before changing any stored field.

```device
source supportedMode "Single read, write, or verify, with optional decrement and reload" (byte: 8): flag {
  single: flag = equal(and(byte, u8($C0)), u8($40))
  reserved: flag = equal(and(byte, u8($0C)), u8($0C))
  return and(single, not(reserved))
}

source writeRegister "Decode the four-bit programming address" (address: 8, byte: 8): flag {
  accepted = match address: flag {
    case "0000 0xxx" {
      perform writeWord(and(bits(address, 3, 1), u3(3)), bit(address, 0), byte)
      return 1
    }
    case "0000 1000" {
      supported: flag = zero(and(byte, u8($FB)))
      when supported {
        COMMAND <- byte
      }
      return supported
    }
    case "0000 1001" {
      return not(bit(byte, 2))
    }
    case "0000 1010" {
      channel = and(byte, u8(3))
      mask = iterate(channel, u8(1)) {
        return shiftLeft(mask, 0)
      }
      old = register MASK
      MASK <- or(and(old, xor(mask, u8($0F))), select(bit(byte, 2), mask, u8(0)))
      return 1
    }
    case "0000 1011" {
      supported = source supportedMode(byte)
      when supported {
        MODE[and(byte, u8(3))] <- and(byte, u8($FC))
      }
      return supported
    }
    case "0000 1100" {
      HIGH_BYTE <- 0
      return 1
    }
    case "0000 1101" {
      perform resetController()
      return 1
    }
    case "0000 1110" {
      MASK <- u8(0)
      return 1
    }
    case "0000 1111" {
      MASK <- and(byte, u8($0F))
      return 1
    }
    otherwise unsupported
  }
  return accepted
}

source readAddress0 "Channel 0 address byte" : 8 {
  byte = source readWord(u3(0), 0)
  return byte
}
source readCount0 "Channel 0 count byte" : 8 {
  byte = source readWord(u3(0), 1)
  return byte
}
source readAddress1 "Channel 1 address byte" : 8 {
  byte = source readWord(u3(1), 0)
  return byte
}
source readCount1 "Channel 1 count byte" : 8 {
  byte = source readWord(u3(1), 1)
  return byte
}
source readAddress2 "Channel 2 address byte" : 8 {
  byte = source readWord(u3(2), 0)
  return byte
}
source readCount2 "Channel 2 count byte" : 8 {
  byte = source readWord(u3(2), 1)
  return byte
}
source readAddress3 "Channel 3 address byte" : 8 {
  byte = source readWord(u3(3), 0)
  return byte
}
source readCount3 "Channel 3 count byte" : 8 {
  byte = source readWord(u3(3), 1)
  return byte
}

source validMode "A channel is unconfigured or has a supported mode without selector bits" (channel: 3): flag {
  mode = array MODE[and(channel, u3(3))]
  supported = source supportedMode(mode)
  return or(zero(mode), and(supported, zero(and(mode, u8(3)))))
}

source validState "Restore only implemented control words and four-bit status/mask fields" : flag {
  command = register COMMAND
  mask = register MASK
  levels = register LEVELS
  terminal = register TERMINAL
  channel0 = source validMode(u3(0))
  channel1 = source validMode(u3(1))
  channel2 = source validMode(u3(2))
  channel3 = source validMode(u3(3))
  modes: flag = and(and(channel0, channel1), and(channel2, channel3))
  return and(modes, and(zero(and(command, u8($FB))), zero(and(or(mask, or(levels, terminal)), u8($F0)))))
}

interface I8237a {
  size 16
  initialize initialize
  reset resetController
  validate validState
  input setRequests
  input completeTransfer
  view pending
  view transferChannel
  view transferReady
  view transferAddress
  view readTransfer
  view writeTransfer
  read 0 readAddress0
  read 1 readCount0
  read 2 readAddress1
  read 3 readCount1
  read 4 readAddress2
  read 5 readCount2
  read 6 readAddress3
  read 7 readCount3
  read 8 status
  read 13 temporary
  write * writeRegister
}
```

A snapshot includes all channel/base/mode arrays, request levels, masks,
terminal flags, command, and the shared byte selector. Restoring it does not
replay initialization or consume a register byte. Returned arrays are detached.
The validator admits zero unconfigured mode words only as the model's initial
state; they cannot service requests until programmed.
