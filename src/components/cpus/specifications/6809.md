# Motorola 6809

The 6809 extends Motorola's accumulator-oriented programming model with a
combined sixteen-bit D register, a movable direct page, two stack pointers,
and richer indexed addressing. D is A:B, not separate storage. Its two bytes
remain independently accessible as A and B.

This chapter owns the complete stored-state schema, D and CC views and writes,
and the base-page load/store, arithmetic, logic, and comparison forms that use
immediate, direct, or extended operands. Its `cpu` fences generate production
code. Indexed postbytes, prefixed opcode pages, other instructions, and the
execution lifecycle remain in TypeScript during this migration. The
[model contract](../../../../docs/cpus/6809/model.md) retains hardware references,
public API contracts, reset, interrupt, and failure policies.

## Stored state

A and B hold bytes; X/Y are index registers, S/U are independent stack pointers,
and PC selects the next instruction. DP supplies the high byte for direct
addressing. All addresses wrap at sixteen bits. Initial state is explicit:
construction does not reset registers, read vectors, or fabricate stack frames.

The eight CC flags are E/F/H/I/N/Z/V/C. E records the saved interrupt-frame
shape; F and I mask FIRQ and IRQ. H supports decimal adjustment; N/Z/V/C describe
arithmetic and logical results. NMI recognition also depends on the separate
arming latch. The wait choice distinguishes ordinary execution, SYNC, and CWAI;
a Boolean cannot preserve their different wake-up and saved-frame rules.
The declaration preserves existing public names and state-copy order.

```cpu
cpu "6809"
state {
  register A: 8
  register B: 8
  register DP: 8
  register X: 16
  register Y: 16
  register S: 16
  register U: 16
  register PC: 16
  choice WAIT: "none", "sync", "cwai" = waitMode
  latch NMIARMED = nmiArmed
  flag E
  flag F
  flag H
  flag I
  flag N
  flag Z
  flag V
  flag C
}
```

## Register views and writes

Read A before B to assemble D. Writing D captures a complete word, then replaces
A followed by B. Instructions, snapshots, and indexed D offsets use this same
view; transfers, stacks, multiplication, and arithmetic use the same write action.
Neither operation changes CC or touches memory.

```cpu
view D "D from A:B": 16 {
  high = register A
  low = register B
  return concat(high, low)
}
action writeD "write D as A then B" (word: 16) {
  A <- highByte(word)
  B <- lowByte(word)
}
```

CC is `EFHINZVC`; every bit is stored. Packing reads flags from bit seven to
bit zero. Restoring CC replaces the entire flag object. Register transfers,
stack frames, software interrupts, and external entry all use these definitions.
The mask action captures packed CC before applying the supplied mask; the
remaining core selects that mask and decides when entry is allowed.

```cpu
view CC "packed condition codes": 8 {
  e = flag E
  f = flag F
  h = flag H
  i = flag I
  n = flag N
  z = flag Z
  v = flag V
  c = flag C
  ef = or(select(e, u8($80), u8($00)), select(f, u8($40), u8($00)))
  hi = or(select(h, u8($20), u8($00)), select(i, u8($10), u8($00)))
  nz = or(select(n, u8($08), u8($00)), select(z, u8($04), u8($00)))
  vc = or(select(v, u8($02), u8($00)), select(c, u8($01), u8($00)))
  return or(or(ef, hi), or(nz, vc))
}
policy CCFLAGS "restore all condition codes" (status: 8) {
  E = not(zero(and(status, u8($80))))
  F = not(zero(and(status, u8($40))))
  H = not(zero(and(status, u8($20))))
  I = not(zero(and(status, u8($10))))
  N = not(zero(and(status, u8($08))))
  Z = not(zero(and(status, u8($04))))
  V = not(zero(and(status, u8($02))))
  C = not(zero(and(status, u8($01))))
}
action maskCC "set interrupt masks in CC" (mask: 8) {
  status = source CC
  replace CCFLAGS(or(status, mask))
}
```

## Addressing and encodings

The base-page accumulator pattern is `1 r mm oooo`: `r=0/1` selects A/B,
`mm=00/01/10/11` selects immediate/direct/indexed/extended, and `oooo` selects
the operation. This slice owns `00`, `01`, and `11`. Its memory-only pattern
`1 r m1 oooo` uses `m=0/1` for direct/extended; indexed `mm=10` remains outside
the chapter. No placeholder source pretends to implement indexed addressing.

Immediate bytes are instruction fetches. Immediate words fetch high then low.
A direct operand fetches its offset **before** reading DP; the address is DP:offset.
For example, DP=`$12` and offset=`$34` select `$1234`. Extended addressing fetches
an absolute high/low pair. Captures preserve the resolved address even when a
subsequent memory callback changes live registers.

```cpu
source immediateByte "#byte": 8 {
  byte = fetch
  return byte
}
source immediateWord "#word": 16 {
  high = fetch
  low = fetch
  return concat(high, low)
}
source direct "direct": 16 {
  offset = fetch
  page = register DP
  return concat(page, offset)
}
source extended "extended": 16 {
  high = fetch
  low = fetch
  return concat(high, low)
}
operands accumulators {
  0 "A" = register A
  1 "B" = register B
}
operands memoryModes {
  0 "direct" = memory direct
  1 "extended" = memory extended
}
```

Word data reads use the captured address, high byte first, then the following
address with sixteen-bit wrap. A direct word at `$12FF` continues at `$1300`,
not `$1200`; a word at `$FFFF` continues at `$0000`. The same addressing sources
serve stores, which never read the destination.

```cpu
source directWord "direct word": 16 {
  address = source direct
  high = memory(address)
  low = memory(add(address, u16($0001)))
  return concat(high, low)
}
source extendedWord "extended word": 16 {
  address = source extended
  high = memory(address)
  low = memory(add(address, u16($0001)))
  return concat(high, low)
}
operands wordMemory {
  0 "direct" = value directWord
  1 "extended" = value extendedWord
}
operands indexRegisters {
  0 "X" = register X
  1 "U" = register U
}
```

## Loads and stores

Loads and stores set N/Z from the complete byte or word, clear V, and preserve
E/F/H/I/C. Loads write their register before flags. Stores apply flags only after
every write succeeds; a failed second word write retains the first byte and old
flags. Repeated writes are observable even if the value is unchanged.

```cpu
policy RESULT8 "byte result" (result: 8) {
  N = negative(result)
  Z = zero(result)
  V = 0
}
policy RESULT16 "word result" (result: 16) {
  N = negative(result)
  Z = zero(result)
  V = 0
}
```

LDA/LDB use operation `0110`. Fetch or read the complete operand, write the
selected accumulator, then set N/Z and clear V. Preserve the other accumulator,
all pointers, and E/F/H/I/C. A failed operand read prevents register and flag updates.

```cpu
family LD {
  encoding "1 r 00 0110" for r in accumulators with m = immediateByte named "LD{r} #byte"
  encoding "1 r m1 0110" for r in accumulators, m in memoryModes.read named "LD{r} {m}"
  result = source m
  operand r <- result
  apply RESULT8(result)
}
```

STA/STB use operation `0111`, with no immediate encoding. Resolve the whole
address before reading A/B, write that byte once, then set N/Z and clear V.
Preserve E/F/H/I/C; a failed write retains old flags and completed fetching.

```cpu
family ST "1 r m1 0111" for r in accumulators, m in memoryModes.address named "ST{r} {m}" {
  address = source m
  result = operand r
  memory(address) <- result
  apply RESULT8(result)
}
```

`1 r mm 1110` selects LDX when `r=0`, LDU when `r=1`. Read or fetch high/low,
then replace the selected pointer and apply word-wide N/Z with V clear. Preserve
all other state; a partial read never replaces the pointer.

```cpu
family LDindex {
  encoding "1 r 00 1110" for r in indexRegisters with m = immediateWord named "LD{r} #word"
  encoding "1 r m1 1110" for r in indexRegisters, m in wordMemory.read named "LD{r} {m}"
  result = source m
  operand r <- result
  apply RESULT16(result)
}
```

`1 r mm 1111` selects STX/STU and has no immediate form. Resolve the address,
capture the selected word, write high/low with sixteen-bit address wrap, then
apply word-wide N/Z and clear V. Preserve E/F/H/I/C and the source pointer.

```cpu
family STindex "1 r m1 1111" for r in indexRegisters, m in memoryModes.address named "ST{r} {m}" {
  address = source m
  result = operand r
  memory(address) <- highByte(result)
  memory(add(address, u16($0001))) <- lowByte(result)
  apply RESULT16(result)
}
```

LDD uses `11 mm 1100`. Read or fetch both bytes before writing D as A then B;
then set word-wide N/Z and clear V. Preserve E/F/H/I/C and all pointers.
A failed read leaves both accumulators and CC unchanged.

```cpu
family LDD {
  encoding "11 00 1100" with m = immediateWord named "LDD #word"
  encoding "11 m1 1100" for m in wordMemory.read named "LDD {m}"
  result = source m
  perform writeD(result)
  apply RESULT16(result)
}
```

STD uses `11 mm 1101`, excluding the immediate slot. Resolve the address,
capture A then B through D, write high/low, then set word-wide N/Z and clear V.
Capture both source bytes before either write; memory callbacks cannot change
this stored word. Preserve registers and E/F/H/I/C.

```cpu
family STD "11 m1 1101" for m in memoryModes.address named "STD {m}" {
  address = source m
  result = source D
  memory(address) <- highByte(result)
  memory(add(address, u16($0001))) <- lowByte(result)
  apply RESULT16(result)
}
```

## Logic and bit tests

AND, BIT, EOR, and OR use operations `0100`, `0101`, `1000`, and `1010`.
They read the operand before A/B. N/Z describe the combined byte and V clears;
E/F/H/I/C are preserved. BIT differs from AND only by omitting writeback.

AND reads or fetches the operand, then captures the selected accumulator.
Compute bitwise AND. Write the result before applying flags.
Set N/Z and clear V; preserve E/F/H/I/C. A failed operand read prevents all
register and flag effects.

```cpu
family AND {
  encoding "1 r 00 0100" for r in accumulators with m = immediateByte named "AND{r} #byte"
  encoding "1 r m1 0100" for r in accumulators, m in memoryModes.read named "AND{r} {m}"
  right = source m
  left = operand r
  result = and(left, right)
  operand r <- result
  apply RESULT8(result)
}
```

BIT reads or fetches the operand, then captures the selected accumulator.
Compute bitwise AND. Preserve both accumulators without writing a result.
Set N/Z and clear V; preserve E/F/H/I/C. A failed operand read prevents all
register and flag effects.

```cpu
family BIT {
  encoding "1 r 00 0101" for r in accumulators with m = immediateByte named "BIT{r} #byte"
  encoding "1 r m1 0101" for r in accumulators, m in memoryModes.read named "BIT{r} {m}"
  right = source m
  left = operand r
  result = and(left, right)
  apply RESULT8(result)
}
```

EOR reads or fetches the operand, then captures the selected accumulator.
Compute bitwise XOR. Write the result before applying flags.
Set N/Z and clear V; preserve E/F/H/I/C. A failed operand read prevents all
register and flag effects.

```cpu
family EOR {
  encoding "1 r 00 1000" for r in accumulators with m = immediateByte named "EOR{r} #byte"
  encoding "1 r m1 1000" for r in accumulators, m in memoryModes.read named "EOR{r} {m}"
  right = source m
  left = operand r
  result = xor(left, right)
  operand r <- result
  apply RESULT8(result)
}
```

OR reads or fetches the operand, then captures the selected accumulator.
Compute bitwise OR. Write the result before applying flags.
Set N/Z and clear V; preserve E/F/H/I/C. A failed operand read prevents all
register and flag effects.

```cpu
family OR {
  encoding "1 r 00 1010" for r in accumulators with m = immediateByte named "OR{r} #byte"
  encoding "1 r m1 1010" for r in accumulators, m in memoryModes.read named "OR{r} {m}"
  right = source m
  left = operand r
  result = or(left, right)
  operand r <- result
  apply RESULT8(result)
}
```

## Comparison

CMPA/CMPB use byte operation `0001`; CMPX uses `10 mm 1100`. All three read
the operand first and preserve the compared register. Subtraction sets N/Z/V/C,
with C meaning unsigned borrow, while E/F/H/I remain unchanged. Unlike the
original 6800 CPX, CMPX uses a full sixteen-bit subtraction, including low-byte
borrow in N/V. X=`$1200` compared with `$1201` therefore gives N=1, Z=0, V=0, C=1.

```cpu
policy COMPARE8 "8-bit comparison" (left: 8, right: 8, result: 8) {
  N = negative(result)
  Z = zero(result)
  V = overflow(left, right)
  C = borrow(left, right)
}
```

```cpu
policy COMPARE16 "16-bit comparison" (left: 16, right: 16, result: 16) {
  N = negative(result)
  Z = zero(result)
  V = overflow(left, right)
  C = borrow(left, right)
}
```

CMPA/CMPB read or fetch a byte before capturing A/B. Subtract without using
incoming C; set N/Z/V/C and preserve E/F/H/I. Neither accumulator is written,
and no flag changes if the operand read fails.

```cpu
family CMP {
  encoding "1 r 00 0001" for r in accumulators with m = immediateByte named "CMP{r} #byte"
  encoding "1 r m1 0001" for r in accumulators, m in memoryModes.read named "CMP{r} {m}"
  right = source m
  left = operand r
  result = subtract(left, right)
  apply COMPARE8(left, right, result)
}
```

CMPX reads or fetches a high-first word, then captures X. Subtract at sixteen
bits without incoming C; set N/Z/V/C while preserving E/F/H/I and every
register. A failed first or second byte read prevents flag updates.

```cpu
family CMPX {
  encoding "10 00 1100" with m = immediateWord named "CMPX #word"
  encoding "10 m1 1100" for m in wordMemory.read named "CMPX {m}"
  right = source m
  left = register X
  result = subtract(left, right)
  apply COMPARE16(left, right, result)
}
```

## Arithmetic

Byte SUB/SBC/ADC/ADD use operations `0000`, `0010`, `1001`, and `1011`.
SUBD/ADDD use `1 r mm 0011`, with `r=0` subtracting and `r=1` adding.
Read the operand, then the accumulator, then any incoming C. Calculate with
byte or word wrap; replace arithmetic flags **before** register writeback.

Addition records unsigned carry and signed overflow; byte addition also sets H
from bit-three carry. Subtraction records borrow and signed overflow while
preserving H. Word arithmetic preserves H too. E/F/I never change. Subtracting
`$FF` with incoming borrow from a byte subtracts 256, not zero; the wrapped
result and carry/borrow tests deliberately use the original operands.

```cpu
policy ADD8 "8-bit add" (left: 8, right: 8, result: 8, incoming: flag) {
  N = negative(result)
  Z = zero(result)
  V = addOverflow(left, right, incoming)
  C = carry(left, right, incoming)
  H = halfCarry(left, right, incoming)
}
```

```cpu
policy SUB8 "8-bit sub" (left: 8, right: 8, result: 8, incoming: flag) {
  N = negative(result)
  Z = zero(result)
  V = overflow(left, right, incoming)
  C = borrow(left, right, incoming)
}
```

```cpu
policy ADD16 "16-bit add" (left: 16, right: 16, result: 16) {
  N = negative(result)
  Z = zero(result)
  V = addOverflow(left, right)
  C = carry(left, right)
}
```

```cpu
policy SUB16 "16-bit sub" (left: 16, right: 16, result: 16) {
  N = negative(result)
  Z = zero(result)
  V = overflow(left, right)
  C = borrow(left, right)
}
```

SUB reads or fetches the operand, then captures A/B. Ignore incoming C.
Subtract with byte wrap, update N/Z/V/C, preserving H, then write the selected
accumulator. Preserve E/F/I and all other registers. Failed reads prevent flags
and writeback; completed instruction fetches remain visible.

```cpu
family SUB {
  encoding "1 r 00 0000" for r in accumulators with m = immediateByte named "SUB{r} #byte"
  encoding "1 r m1 0000" for r in accumulators, m in memoryModes.read named "SUB{r} {m}"
  right = source m
  left = operand r
  result = subtract(left, right)
  apply SUB8(left, right, result, 0)
  operand r <- result
}
```

SBC reads or fetches the operand, then captures A/B. Capture C as incoming borrow.
Subtract with byte wrap, update N/Z/V/C, preserving H, then write the selected
accumulator. Preserve E/F/I and all other registers. Failed reads prevent flags
and writeback; completed instruction fetches remain visible.

```cpu
family SBC {
  encoding "1 r 00 0010" for r in accumulators with m = immediateByte named "SBC{r} #byte"
  encoding "1 r m1 0010" for r in accumulators, m in memoryModes.read named "SBC{r} {m}"
  right = source m
  left = operand r
  incoming = flag C
  result = subtract(left, right, incoming)
  apply SUB8(left, right, result, incoming)
  operand r <- result
}
```

ADC reads or fetches the operand, then captures A/B. Capture C as incoming carry.
Add with byte wrap, update N/Z/V/C/H, then write the selected
accumulator. Preserve E/F/I and all other registers. Failed reads prevent flags
and writeback; completed instruction fetches remain visible.

```cpu
family ADC {
  encoding "1 r 00 1001" for r in accumulators with m = immediateByte named "ADC{r} #byte"
  encoding "1 r m1 1001" for r in accumulators, m in memoryModes.read named "ADC{r} {m}"
  right = source m
  left = operand r
  incoming = flag C
  result = add(left, right, incoming)
  apply ADD8(left, right, result, incoming)
  operand r <- result
}
```

ADD reads or fetches the operand, then captures A/B. Ignore incoming C.
Add with byte wrap, update N/Z/V/C/H, then write the selected
accumulator. Preserve E/F/I and all other registers. Failed reads prevent flags
and writeback; completed instruction fetches remain visible.

```cpu
family ADD {
  encoding "1 r 00 1011" for r in accumulators with m = immediateByte named "ADD{r} #byte"
  encoding "1 r m1 1011" for r in accumulators, m in memoryModes.read named "ADD{r} {m}"
  right = source m
  left = operand r
  result = add(left, right)
  apply ADD8(left, right, result, 0)
  operand r <- result
}
```

SUBD reads or fetches both operand bytes before capturing A then B through D.
Subtract with sixteen-bit wrap, ignoring incoming C. Apply N/Z/V/C, then write
D as A followed by B. Preserve E/F/H/I and all pointers. A partial operand read
leaves the complete destination and flags unchanged.

```cpu
family SUBD {
  encoding "1 0 00 0011" with m = immediateWord named "SUBD #word"
  encoding "1 0 m1 0011" for m in wordMemory.read named "SUBD {m}"
  right = source m
  left = source D
  result = subtract(left, right)
  apply SUB16(left, right, result)
  perform writeD(result)
}
```

ADDD reads or fetches both operand bytes before capturing A then B through D.
Add with sixteen-bit wrap, ignoring incoming C. Apply N/Z/V/C, then write
D as A followed by B. Preserve E/F/H/I and all pointers. A partial operand read
leaves the complete destination and flags unchanged.

```cpu
family ADDD {
  encoding "1 1 00 0011" with m = immediateWord named "ADDD #word"
  encoding "1 1 m1 0011" for m in wordMemory.read named "ADDD {m}"
  right = source m
  left = source D
  result = add(left, right)
  apply ADD16(left, right, result)
  perform writeD(result)
}
```

The [CPU tests](../../../../tests/components/cpus/6809.test.ts) retain independent
opcode, arithmetic, addressing, interrupt, and failure expectations. The

The 88 forms here are complete from operand fetching through writeback. Indexed
forms still use native postbyte decoding and resolved-memory bodies. Prefixed
pages retain their existing instruction definitions and bindings. Other base
instructions, reset, execution, SYNC/CWAI, NMI arming, IRQ/FIRQ/NMI recognition,
and frame selection remain outside this chapter; the [coverage tracker](../../../../docs/cpus/coverage.md#6809)
records their migration separately from implemented CPU support.
