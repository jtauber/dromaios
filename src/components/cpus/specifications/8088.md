# Intel 8088

This chapter begins the executable guide to Dromaios's original Intel 8088.
It owns stored state, byte-register views and writes, packed FLAGS, and the
segmented memory/ModR/M operands, and the instruction families defined below.
All documented instruction forms are defined here. The prefix decoder, reset,
and execution boundary still live in TypeScript. Their
[model contract](../../../../docs/cpus/8088/model.md) remains authoritative
until those parts migrate; the [coverage report](../../../../docs/cpus/coverage.md#8088)
measures that work separately from instruction support.

## Historical background

Intel introduced the 8088 in 1979, following the 8086 in 1978. It retains the
8086's sixteen-bit programmer's architecture while using an eight-bit external
data bus. IBM chose the 8088 for the IBM PC, introduced in August 1981.
Intel's [processor chronology][chronology] and [account of the IBM PC][history]
provide the historical context; its [family manual][manual] describes the
architecture and instruction encodings used here.

That eight-bit bus does not make AX an eight-bit register. A word calculation
still operates on sixteen bits; transferring a word to memory takes two byte
transfers. The physical processor separates instruction execution from bus
activity and uses a four-byte instruction queue. Dromaios models ordered
instruction effects, without a prefetch queue or clock timing. Its recorded
accesses therefore describe the emulator's observations, not a cycle trace.

## The programmer's machine

| Registers | Role |
| --- | --- |
| AX, BX, CX, DX | Word registers with independently addressable low/high bytes |
| SP, BP, SI, DI | Word registers used for stacks, addressing, and string operations |
| CS, DS, SS, ES | Segment registers supplying the base of a 64 KiB address window |
| IP | Offset of the next instruction within CS |
| FLAGS | Arithmetic results and the TF/IF/DF control flags |

AL and AH are views of AX's low and high bytes. If AX is `$1234`, AL is `$34`
and AH is `$12`. Writing `$56` to AL gives AX=`$1256`; there is no separate
AL value to synchronize. The same relationship holds for BX, CX, and DX.
SP, BP, SI, and DI do not have separately addressable byte halves on this chip.

A memory address combines a segment and offset: shift the segment left four
bits, add the sixteen-bit offset, and keep the low twenty bits. Thus
`1234:0010` and `1235:0000` both select physical `$12350`. At the top of the
address space, `FFFF:0010` wraps to zero. IP wraps within its segment;
advancing it does not carry into CS. The snapshot's `pc` is a derived physical
CS:IP view, while instruction fetching still belongs to the native decoder.

Immediate words and memory words are little-endian: `MOV AX,1234H` is encoded
`$B8 $34 $12`. Here `$` introduces hexadecimal, while binary opcode patterns
run from most to least significant bit. Register selectors follow the
hardware encoding order, which differs from the stored-state listing.

## Stored state

The schema owns the public fields and validation rules used by construction,
snapshots, and `.machine` parsing. Registers and flags use uppercase names in
the formal language and lowercase fields in TypeScript. FLAGS is a group of
Boolean fields, not a second stored integer.

STOPPED and WAITING distinguish HLT from a WAIT instruction held by TEST.
INTRDEFERRED delays maskable recognition; RECOGNITIONDEFERRED inhibits all
recognition at a boundary; TRAPPENDING records an owed single-step trap.
These latches represent model bookkeeping, not extra architectural registers.
The caller supplies initial values; construction is separate from reset.

```cpu
cpu "8088"
state {
  register AX: 16
  register BX: 16
  register CX: 16
  register DX: 16
  register SP: 16
  register BP: 16
  register SI: 16
  register DI: 16
  register CS: 16
  register DS: 16
  register SS: 16
  register ES: 16
  register IP: 16
  latch STOPPED = halted
  latch WAITING = waiting
  latch INTRDEFERRED = interruptDeferred
  latch RECOGNITIONDEFERRED = recognitionDeferred
  latch TRAPPENDING = trapPending
  flag CF
  flag PF
  flag AF
  flag ZF
  flag SF
  flag TF
  flag IF
  flag DF
  flag OF
}
```

## Byte views and writes

Each read captures its stored word once. A write captures the **live** word
again at writeback, preserving its other half even if a fetch or flag update
has changed that word since the earlier operand read. Actions own their local
captures, so several byte writes can occur in one instruction without sharing
temporary values. Native instruction definitions use these same chapter views
and actions while their bodies await migration.

```cpu
view AL "low byte of AX": 8 {
  word = register AX
  return lowByte(word)
}
action setAL "write AL, preserving its other half" (byte: 8) {
  preservedWord = register AX
  AX <- concat(highByte(preservedWord), byte)
}
view CL "low byte of CX": 8 {
  word = register CX
  return lowByte(word)
}
action setCL "write CL, preserving its other half" (byte: 8) {
  preservedWord = register CX
  CX <- concat(highByte(preservedWord), byte)
}
view DL "low byte of DX": 8 {
  word = register DX
  return lowByte(word)
}
action setDL "write DL, preserving its other half" (byte: 8) {
  preservedWord = register DX
  DX <- concat(highByte(preservedWord), byte)
}
view BL "low byte of BX": 8 {
  word = register BX
  return lowByte(word)
}
action setBL "write BL, preserving its other half" (byte: 8) {
  preservedWord = register BX
  BX <- concat(highByte(preservedWord), byte)
}
view AH "high byte of AX": 8 {
  word = register AX
  return highByte(word)
}
action setAH "write AH, preserving its other half" (byte: 8) {
  preservedWord = register AX
  AX <- concat(byte, lowByte(preservedWord))
}
view CH "high byte of CX": 8 {
  word = register CX
  return highByte(word)
}
action setCH "write CH, preserving its other half" (byte: 8) {
  preservedWord = register CX
  CX <- concat(byte, lowByte(preservedWord))
}
view DH "high byte of DX": 8 {
  word = register DX
  return highByte(word)
}
action setDH "write DH, preserving its other half" (byte: 8) {
  preservedWord = register DX
  DX <- concat(byte, lowByte(preservedWord))
}
view BH "high byte of BX": 8 {
  word = register BX
  return highByte(word)
}
action setBH "write BH, preserving its other half" (byte: 8) {
  preservedWord = register BX
  BX <- concat(byte, lowByte(preservedWord))
}
view PC "physical CS:IP": 32 {
  segment = register CS
  offset = register IP
  return and(add(shiftBits(extend(segment, 32), left, 4), extend(offset, 32)), u32($FFFFF))
}
```

The language uses a thirty-two-bit result for PC and explicitly masks it to
the twenty-bit bus. Stored CS and IP remain sixteen-bit values.

## FLAGS as a packed value

CF records carry or borrow, PF even parity of the low result byte, AF the
bit-3 carry or borrow, ZF zero, SF the result sign bit, and OF signed overflow.
TF requests single-stepping, IF permits maskable interrupts, and DF selects
the string-operation direction. An arithmetic instruction changes only the
flags specified by its policy; loading a register does not recompute flags.

The low byte is `SF ZF 0 AF 0 PF 1 CF`. The full original-chip FLAGS word
adds TF/IF/DF/OF in bits 8–11 and sets bits 12–15. Packing reads CF/PF/AF/ZF/SF,
then TF/IF/DF/OF for the word. Reserved bits are ignored on restoration.
SAHF updates five fields of the existing flags object. Full restoration
replaces all nine fields, and is shared by POPF and IRET. Their
interrupt-deferral and stack rules remain with those instructions.

```cpu
view LOWFLAGS "packed low FLAGS": 8 {
  cf = flag CF
  pf = flag PF
  af = flag AF
  zf = flag ZF
  sf = flag SF
  cfBit = select(cf, u8($01), u8(0))
  pfBit = select(pf, u8($04), u8(0))
  afBit = select(af, u8($10), u8(0))
  zfBit = select(zf, u8($40), u8(0))
  sfBit = select(sf, u8($80), u8(0))
  return or(or(or(or(or(u8($02), cfBit), pfBit), afBit), zfBit), sfBit)
}
policy RESTORELOWFLAGS "restore LOWFLAGS" (status: 8) {
  CF = not(zero(and(status, u8($01))))
  PF = not(zero(and(status, u8($04))))
  AF = not(zero(and(status, u8($10))))
  ZF = not(zero(and(status, u8($40))))
  SF = not(zero(and(status, u8($80))))
}
view FLAGS "packed FLAGS word": 16 {
  cf = flag CF
  pf = flag PF
  af = flag AF
  zf = flag ZF
  sf = flag SF
  tf = flag TF
  if = flag IF
  df = flag DF
  of = flag OF
  cfBit = select(cf, u16($0001), u16(0))
  pfBit = select(pf, u16($0004), u16(0))
  afBit = select(af, u16($0010), u16(0))
  zfBit = select(zf, u16($0040), u16(0))
  sfBit = select(sf, u16($0080), u16(0))
  tfBit = select(tf, u16($0100), u16(0))
  ifBit = select(if, u16($0200), u16(0))
  dfBit = select(df, u16($0400), u16(0))
  ofBit = select(of, u16($0800), u16(0))
  arithmetic = or(cfBit, or(pfBit, or(afBit, or(zfBit, sfBit))))
  controls = or(tfBit, or(ifBit, or(dfBit, ofBit)))
  return or(u16($F002), or(arithmetic, controls))
}
policy RESTOREFLAGS "restore FLAGS" (status: 16) {
  CF = not(zero(and(status, u16($0001))))
  PF = not(zero(and(status, u16($0004))))
  AF = not(zero(and(status, u16($0010))))
  ZF = not(zero(and(status, u16($0040))))
  SF = not(zero(and(status, u16($0080))))
  TF = not(zero(and(status, u16($0100))))
  IF = not(zero(and(status, u16($0200))))
  DF = not(zero(and(status, u16($0400))))
  OF = not(zero(and(status, u16($0800))))
}
action restoreFlags "replace all FLAGS" (status: 16) {
  replace RESTOREFLAGS(status)
}
```

`1001 111d` selects SAHF (`d=0`) or LAHF (`d=1`). SAHF captures AH before
updating CF/PF/AF/ZF/SF in layout order; OF/TF/IF/DF and all registers survive.
LAHF packs the low flags before writing AH, preserving live AL at writeback
and leaving all flags unchanged.

```cpu
family SAHF "1001 1110" {
  status = source AH
  apply RESTORELOWFLAGS(status)
}
family LAHF "1001 1111" {
  status = source LOWFLAGS
  perform setAH(status)
}
```

## Register selectors and immediate operands

The `rrr` field selects byte or word operands according to the instruction's
width bit. The common order is explicit in these catalogues; SP is not AH,
even though both occupy selector `100` in their respective widths.

```cpu
operands bytes {
  000 "AL" = view AL write setAL
  001 "CL" = view CL write setCL
  010 "DL" = view DL write setDL
  011 "BL" = view BL write setBL
  100 "AH" = view AH write setAH
  101 "CH" = view CH write setCH
  110 "DH" = view DH write setDH
  111 "BH" = view BH write setBH
}
operands words {
  000 "AX" = register AX
  001 "CX" = register CX
  010 "DX" = register DX
  011 "BX" = register BX
  100 "SP" = register SP
  101 "BP" = register BP
  110 "SI" = register SI
  111 "DI" = register DI
}
source immediateByte "immediate byte": 8 {
  byte = fetch
  return byte
}
source immediateWord "immediate word, low byte first": 16 {
  low = fetch
  high = fetch
  return concat(high, low)
}
```

## Immediate register loads

`1011 w rrr` selects MOV: `w=0` takes one immediate byte, `w=1` a low-first
word. Fetch the complete immediate before writing the destination. Byte
writes retain the current other half of the stored word. Preserve every
flag; a failed fetch leaves the destination untouched, while completed fetches
and IP advances remain.

```cpu
family MOVbyte "1011 0 rrr" for r in bytes named "MOV {r},n" {
  result = source immediateByte
  operand r <- result
}
family MOVword "1011 1 rrr" for r in words named "MOV {r},n" {
  result = source immediateWord
  operand r <- result
}
```

## Arithmetic and logical flags

Addition and subtraction update CF, AF, OF, ZF, SF, and PF in that order.
CF describes unsigned overflow or borrow; OF describes signed overflow.
For example, byte `$7F + 1` produces `$80` with OF set and CF clear, while
`$FF + 1` produces zero with CF set and OF clear. Both cross a nibble boundary.
Word parity still considers only the low byte, unlike word zero and sign.

Logical operations clear OF, CF, and AF in that order, then set ZF/SF/PF.
Hardware leaves AF undefined for these operations; clearing it is this model's
deterministic choice. Every policy preserves TF/IF/DF. Right-hand expressions
use captured operands and are evaluated before the first flag write. These
policies serve the chapter’s arithmetic and logical families, each retaining
its own operand decoding and effect order.

```cpu
policy ADD8FLAGS "8088 ADD flags" (left: 8, right: 8, result: 8, incoming: flag) {
  CF = carry(left, right, incoming)
  AF = halfCarry(left, right, incoming)
  OF = addOverflow(left, right, incoming)
  ZF = zero(result)
  SF = negative(result)
  PF = evenParity(result)
}
policy SUB8FLAGS "8088 SUB flags" (left: 8, right: 8, result: 8, incoming: flag) {
  CF = borrow(left, right, incoming)
  AF = halfBorrow(left, right, incoming)
  OF = overflow(left, right, incoming)
  ZF = zero(result)
  SF = negative(result)
  PF = evenParity(result)
}
policy LOGIC8 "8088 logical flags" (result: 8) {
  OF = 0
  CF = 0
  AF = 0
  ZF = zero(result)
  SF = negative(result)
  PF = evenParity(result)
}
policy ADD16FLAGS "8088 ADD flags" (left: 16, right: 16, result: 16, incoming: flag) {
  CF = carry(left, right, incoming)
  AF = halfCarry(left, right, incoming)
  OF = addOverflow(left, right, incoming)
  ZF = zero(result)
  SF = negative(result)
  PF = evenParity(lowByte(result))
}
policy SUB16FLAGS "8088 SUB flags" (left: 16, right: 16, result: 16, incoming: flag) {
  CF = borrow(left, right, incoming)
  AF = halfBorrow(left, right, incoming)
  OF = overflow(left, right, incoming)
  ZF = zero(result)
  SF = negative(result)
  PF = evenParity(lowByte(result))
}
policy LOGIC16 "8088 logical flags" (result: 16) {
  OF = 0
  CF = 0
  AF = 0
  ZF = zero(result)
  SF = negative(result)
  PF = evenParity(lowByte(result))
}
policy CARRY "restore captured carry" (incoming: flag) {
  CF = incoming
}
```

## Accumulator arithmetic and tests

The overall pattern is `00 ooo 10 w`: `ooo` selects the operation below,
while `w=0/1` selects AL/AX and an immediate byte/word. TEST instead uses
`1010 100 w`, applying AND's flags without replacing the accumulator.

| ooo | Operation | Incoming CF | Write result |
| --- | --- | --- | --- |
| 000 | ADD | Ignored | Yes |
| 001 | OR | Ignored | Yes |
| 010 | ADC | Added | Yes |
| 011 | SBB | Subtracted | Yes |
| 100 | AND | Ignored | Yes |
| 101 | SUB | Ignored | Yes |
| 110 | XOR | Ignored | Yes |
| 111 | CMP | Ignored | No |

Fetch the complete immediate low byte first, then read AL/AX. Only ADC and
SBB read incoming CF, after both operands. Apply flags before accumulator
writeback; byte writes preserve the live upper half of AX. CMP and TEST
never write or reread AX. Failed operand fetches prevent all body effects;
completed fetches and IP changes remain.

### ADD

Do not read incoming flags. Set CF/AF/OF, then ZF/SF/PF from the wrapped result. Write AL/AX after flags and preserve TF/IF/DF.

```cpu
family ADD8 "00 000 10 0" named "ADD AL,n" {
  right = source immediateByte
  left = source AL
  result = add(left, right)
  apply ADD8FLAGS(left, right, result, 0)
  perform setAL(result)
}
family ADD16 "00 000 10 1" named "ADD AX,n" {
```

## Word increment and decrement

`0100 d rrr` selects INC (`d=0`) or DEC (`d=1`) of a word register. Capture
the register, then CF. Add or subtract one with sixteen-bit wrapping, update
arithmetic flags, restore captured CF, and only then write the register.
Preserve TF/IF/DF. This deliberately retains the model's flag-write ordering,
including its transient CF update if a host observer interrupts execution.

```cpu
family INCword "0100 0 rrr" for r in words named "INC {r}" {
  left = operand r
  preservedCarry = flag CF
  right = u16(1)
  result = add(left, right)
  apply ADD16FLAGS(left, right, result, 0)
  apply CARRY(preservedCarry)
  operand r <- result
}
family DECword "0100 1 rrr" for r in words named "DEC {r}" {
  left = operand r
  preservedCarry = flag CF
  right = u16(1)
  result = subtract(left, right)
  apply SUB16FLAGS(left, right, result, 0)
  apply CARRY(preservedCarry)
  operand r <- result
}
```

## Segmented memory and ModR/M operands

A ModR/M byte is `mm ggg rrr`. For the two-operand families, `ggg` selects a
register and `rrr` selects the register or memory operand. In instruction groups,
`ggg` instead selects the operation. `mm=11` means a register; the other modes
select memory, with no displacement, a signed byte, or a word displacement.
The word displacement is added with sixteen-bit wrapping.

| rrr | Memory base | Default segment |
| --- | --- | --- |
| 000 | BX + SI | DS |
| 001 | BX + DI | DS |
| 010 | BP + SI | SS |
| 011 | BP + DI | SS |
| 100 | SI | DS |
| 101 | DI | DS |
| 110 | BP; a direct word offset when mm=00 | SS; DS for the direct form |
| 111 | BX | DS |

The native boundary still scans prefixes. It passes `overridden=0/1` and the
captured `segmentOverride` word to these families. Those are transient inputs,
not stored CPU fields. A segment prefix captures its register when encountered;
a later prefix replaces it. For ModR/M memory, capture the default segment and
base registers **before** fetching displacement bytes, even when overridden.
Absolute accumulator MOV instead fetches its offset before reading DS, and
never reads DS when an override supplies the segment.

A captured logical pointer concatenates segment and offset into thirty-two
bits. It is not a physical address. This preserves the offset boundary when a
word crosses `$FFFF`: wrap the second offset first, then project each byte
onto the twenty-bit bus. Sources take explicit numeric inputs, own their local
captures, and return one value. They do not retain a live address callback.

### Capturing the base and displacement

Each base source reads the default segment first, then the registers in the
order written in the table. The direct form captures DS before fetching the
low-first offset. The two catalogues make its `mm=00, rrr=110` exception explicit.

The zero pointer for a register form is unused. The original ModR/M byte still

## Register/memory transfers

MOV reads only its source before writing its destination. XCHG reads the r/m
operand before the register, captures both originals, and writes r/m before
the register. This order also applies when two byte operands alias one word.

## Unary arithmetic, shifts, and products

Several instructions use ModR/M `mm ooo rrr`: `mm` and `rrr` choose the
operand, while `ooo` extends the primary opcode. Validate that extension
before displacement fetches or operand reads. Capture a memory pointer once;
all later reads and writes use it, even if a callback changes a segment.

### Increment, decrement, complement, and negation

INC and DEC preserve the incoming CF, captured after reading the operand.
NOT complements every bit without reading flags. NEG subtracts the operand
from zero, including the usual subtraction flags. For every width, flag
updates precede writeback; byte writes preserve the live other half.

### One bit at a time

`1101 00 v w` selects shifts and rotates: `v=0` uses one bit, `v=1` uses
CL; `w=0/1` selects byte/word. The original 8088 uses the **full eight-bit
count**, with no later x86 count mask. Capture CL before reading the operand.

| ooo | Operation | Direction | Incoming bit |
| --- | --- | --- | --- |
| 000 | ROL | Left | Outgoing high bit |
| 001 | ROR | Right | Outgoing low bit |
| 010 | RCL | Left | Live CF |
| 011 | RCR | Right | Live CF |
| 100 | SHL | Left | Zero |
| 101 | SHR | Right | Zero |
| 110 | Undocumented | — | Rejected |
| 111 | SAR | Right | Original sign bit |

Each bounded iteration writes CF. RCL/RCR read live CF on every iteration.
Only count one updates OF, from the changed sign bit. Nonzero shifts set
ZF/SF/PF and deterministically clear undefined AF; rotates preserve them.
Count zero still reads and writes the unchanged operand, preserving all flags.

```cpu
policy RESULT8 "zero, sign, and parity" (result: 8) {
  ZF = zero(result)
  SF = negative(result)
  PF = evenParity(result)
}
policy SHIFT8 "shift result" (result: 8) {
  ZF = zero(result)
  SF = negative(result)
  PF = evenParity(result)
  AF = 0
}
policy SHIFTOF8 "one-bit overflow" (before: 8, after: 8) {
  OF = negative(xor(before, after))
}

action shiftRM8 "shift or rotate a resolved 8-bit operand" (postbyte: 8, pointer: 32, count: 8, operation: 8) using memory {
  originalOperand = source readRM8(postbyte, pointer)
  shifted = iterate(count, originalOperand) {
    original = shifted
    result = match operation: 8 {
      case "00000000" {
        result = shiftLeft(original, negative(original))
        apply CARRY(negative(original))
        return result
      }
      case "00000001" {
        result = shiftRight(original, lowBit(original))
        apply CARRY(lowBit(original))
        return result
      }
      case "00000010" {
        incoming = flag CF
        result = shiftLeft(original, incoming)
        apply CARRY(negative(original))
        return result
      }
      case "00000011" {
        incoming = flag CF
        result = shiftRight(original, incoming)
        apply CARRY(lowBit(original))
        return result
      }
      case "00000100" {
        result = shiftLeft(original, 0)
        apply CARRY(negative(original))
        return result
      }
      case "00000101" {
        result = shiftRight(original, 0)
        apply CARRY(lowBit(original))
        return result
      }
      case "00000111" {
        result = shiftRight(original, negative(original))
        apply CARRY(lowBit(original))
        return result
      }
      otherwise unsupported
    }
    return result
  }
  when zero(subtract(count, u8(1))) {
    apply SHIFTOF8(originalOperand, shifted)
  }
  when and(not(borrow(operation, u8(4))), not(zero(count))) {
    apply SHIFT8(shifted)
  }
  perform writeRM8(postbyte, pointer, shifted)
}
```

### Multiply, divide, and the F6/F7 group

`1111 011 w` uses `/0` for immediate TEST, `/2` for NOT, `/3` for NEG,
and `/4`–`/7` for MUL, IMUL, DIV, IDIV. `/1` is undocumented. TEST fetches
its immediate before reading the operand and updates flags without writeback.

Products read the complete source before AL/AX, form the full double-width
result, then write AX (and DX for words). OF then CF indicate whether the
product fits the original width; all other flags are preserved.

Division reads AX or DX then AX after the divisor. Signed division truncates
toward zero; its remainder follows the dividend sign. Zero divisors and
quotient overflow return `divide-error` before any register writes. The
original signed 8088 also rejects the most negative quotient. Successful
byte division writes AL=quotient, AH=remainder; word division writes AX then
DX. Every flag is preserved. The native boundary delivers type 0 using the
post-instruction IP, retaining the original 8088 convention.

```cpu
policy UNSIGNEDPRODUCT8 "product overflow" (product: 16) {
  OF = not(zero(truncate(shiftBits(product, right, 8), 8)))
  CF = not(zero(truncate(shiftBits(product, right, 8), 8)))
}

policy SIGNEDPRODUCT8 "product overflow" (product: 16) {
  OF = not(zero(xor(product, signExtend(truncate(product, 8), 16))))
  CF = not(zero(xor(product, signExtend(truncate(product, 8), 16))))
}

      immediate = source immediateWord
      perform testRM16(postbyte, pointer, immediate)
    }
    case "xx 010 xxx" {
      pointer = source resolvedRM(postbyte, overridden, segmentOverride)
      perform notRM16(postbyte, pointer)
    }
    case "xx 011 xxx" {
      pointer = source resolvedRM(postbyte, overridden, segmentOverride)
      perform negRM16(postbyte, pointer)
    }
    case "xx 100 xxx" {
      pointer = source resolvedRM(postbyte, overridden, segmentOverride)
      originalOperand = source readRM16(postbyte, pointer)
      accumulator = register AX
      product = multiply(accumulator, originalOperand, unsigned)
      AX <- truncate(product, 16)
      DX <- truncate(shiftBits(product, right, 16), 16)
      apply UNSIGNEDPRODUCT16(product)
    }
    case "xx 101 xxx" {
      pointer = source resolvedRM(postbyte, overridden, segmentOverride)
      originalOperand = source readRM16(postbyte, pointer)
      accumulator = register AX
      product = multiply(accumulator, originalOperand, signed)
      AX <- truncate(product, 16)
      DX <- truncate(shiftBits(product, right, 16), 16)
      apply SIGNEDPRODUCT16(product)
    }
    case "xx 110 xxx" {
      pointer = source resolvedRM(postbyte, overridden, segmentOverride)
      originalOperand = source readRM16(postbyte, pointer)
      high = register DX
      low = register AX
      dividend = concat(high, low)
      quotient, remainder = divide(dividend, originalOperand, unsigned) otherwise "divide-error"
      AX <- quotient
      DX <- remainder
    }
    case "xx 111 xxx" {
      pointer = source resolvedRM(postbyte, overridden, segmentOverride)
      originalOperand = source readRM16(postbyte, pointer)
      high = register DX
      low = register AX
      dividend = concat(high, low)
      quotient, remainder = divide(dividend, originalOperand, signed) otherwise "divide-error"
      reject "divide-error" if zero(xor(quotient, u16($8000)))
      AX <- quotient
      DX <- remainder
    }
    otherwise unsupported
  }
}
```

### Decimal digits and sign extension

DAA/DAS (`0010 s111`) adjust packed decimal digits after addition/subtraction;
AAA/AAS (`0011 s111`) adjust unpacked digits. Read AL first, then AH for
unpacked adjustments. The low-digit decision consults AF only if the nibble
is below ten. For packed adjustment, read AF again for the high threshold:
original AL above `$9F` when AF is set, otherwise above `$99`. Only a value
below that threshold needs a CF read. These are ordered decisions, not
unconditional reads of all flags.

Packed correction sets AF then CF, writes AL preserving live AH, then sets
ZF/SF/PF. Unpacked correction adjusts the captured AH and AL independently,
masks AL to four bits, writes AX, then CF and AF. Undefined flags stay intact.

```cpu
source decimalLow "low digit needs correction" (original: 8): 8 {
  decision = match select(not(borrow(and(original, u8($0F)), u8(10))), u8(1), u8(0)): 8 {
    case "00000001" {
      return u8(1)
    }
    case "00000000" {
      incoming = flag AF
      return select(incoming, u8(1), u8(0))
    }
    otherwise unsupported
  }
  return decision
}
source decimalHigh "high digit needs correction" (original: 8): 8 {
  auxiliary = flag AF
  decision = match select(not(borrow(original, select(auxiliary, u8($A0), u8($9A)))), u8(1), u8(0)): 8 {
    case "00000001" {
      return u8(1)
    }
    case "00000000" {
      incoming = flag CF
      return select(incoming, u8(1), u8(0))
    }
    otherwise unsupported
  }
  return decision
}
policy PACKEDCORRECTION "packed decimal correction" (low: 8, high: 8) {
  AF = not(zero(low))
  CF = not(zero(high))
}
policy UNPACKEDCORRECTION "unpacked decimal correction" (low: 8) {
  CF = not(zero(low))
  AF = not(zero(low))
}

  apply RESULT8(result)
}
```

## Indirect control and the FE/FF groups

`1111 111 w` selects INC `/0` and DEC `/1`. Only the word group `$FF`
also allows near CALL `/2`, far CALL `/3`, near JMP `/4`, far JMP `/5`,
and PUSH `/6`. `/7` and register encodings of far pointers are rejected before
address resolution. A far pointer is offset then segment, each low byte first;
wrap the logical offset between words before projecting it to the bus.

Capture targets before stack writes. A near CALL then captures and pushes IP;
a far CALL captures and pushes CS, then captures live IP and pushes it. Commit
the new CS before IP only after the whole frame succeeds. PUSH SP on the
original 8088 captures SP minus two as its source, before the stack action's
independent update of live SP. All paths preserve flags except INC/DEC.

The stack action decrements live SP before reading SS and the new SP, then
writes low byte before high byte. A failed write retains completed effects.
This same action serves near/far calls and indirect PUSH.

```cpu
action pushWord "push a captured word" (word: 16) using memory {
  pointer = register SP
  SP <- subtract(pointer, u16(2))
  segment = register SS
  offset = register SP
  perform store16(concat(segment, offset), word)
}

}
```

## Conditional branches and loops

A relative displacement is added to the post-fetch IP, wrapping within CS.
Every conditional branch fetches its displacement before testing flags, and
only a taken branch reads or writes IP. `0111 ttt p` selects one of eight
positive tests with `ttt`; `p=1` inverts that test.

| ttt | p=0 | p=1 | Positive test |
| --- | --- | --- | --- |
| 000 | JO | JNO | OF |
| 001 | JB | JAE | CF |
| 010 | JE | JNE | ZF |
| 011 | JBE | JA | CF or ZF |
| 100 | JS | JNS | SF |
| 101 | JP | JNP | PF |
| 110 | JL | JGE | SF differs from OF |
| 111 | JLE | JG | ZF or (SF differs from OF) |

Compound conditions short-circuit: JBE/JA read CF before ZF, and JLE/JG read
ZF before SF and OF. The numeric source returns zero or one so the polarity
bit can invert a captured decision without rereading any flag.

```cpu
source branchDecision "ordered branch test" (condition: 8): 8 {
  positive = match shiftBits(condition, right, 1): 8 {
    case "00000000" {
      test = flag OF
      return select(test, u8(1), u8(0))
    }
    case "00000001" {
      test = flag CF
      return select(test, u8(1), u8(0))
    }
    case "00000010" {
      test = flag ZF
      return select(test, u8(1), u8(0))
    }
    case "00000011" {
      first = flag CF
      result = match select(first, u8(1), u8(0)): 8 {
        case "00000001" {
          return u8(1)
        }
        case "00000000" {
          second = flag ZF
          return select(second, u8(1), u8(0))
        }
        otherwise unsupported
      }
      return result
    }
    case "00000100" {
      test = flag SF
      return select(test, u8(1), u8(0))
    }
    case "00000101" {
      test = flag PF
      return select(test, u8(1), u8(0))
    }
    case "00000110" {
      sign = flag SF
      overflow = flag OF
      return select(xor(sign, overflow), u8(1), u8(0))
    }
    case "00000111" {
      first = flag ZF
      result = match select(first, u8(1), u8(0)): 8 {
        case "00000001" {
          return u8(1)
        }
        case "00000000" {
          sign = flag SF
          overflow = flag OF
          return select(xor(sign, overflow), u8(1), u8(0))
        }
        otherwise unsupported
      }
      return result
    }
    otherwise unsupported
  }
  return xor(positive, and(condition, u8(1)))
}
action relativeJump "branch from live post-fetch IP" (offset: 16) {
  position = register IP
  IP <- add(position, offset)
}
```

## Direct stacks, calls, and returns

The existing `pushWord` action owns all word pushes, including native interrupt
frames. A pop captures SS:SP before reading the low/high bytes, then reads and
increments live SP only after both reads succeed. POP SP subsequently replaces
that incremented pointer with the captured word. Memory POP captures its
destination before reading the stack and never reads the destination itself.

`0101 p rrr` selects register PUSH/POP. Original 8088 PUSH SP differs from
other registers: its source is the captured SP minus two, before the stack's
independent pointer update. The separate source makes that exception visible;
all other encoded registers use the ordinary register catalogue.

```cpu
  offset = register SP

  pointer = register SP
  SP <- add(pointer, u16(2))
  return word
}

  return subtract(pointer, u16(2))
}
```

## Simple controls

HLT sets the stored stopped latch; the boundary still owns retirement and
pending traps. CMC complements live CF. CLC/STC and CLD/STD set their selected
flag without reading it. CLI clears IF directly; STI reads IF, requests INTR
deferral only when it was clear, then sets it. None of these bodies commits
recognition latches itself. These requests remain explicit instruction effects.

```cpu
policy DIRECTION "set direction" (enabled: flag) {
  DF = enabled
}
policy INTERRUPTENABLE "set interrupt enable" (enabled: flag) {
  IF = enabled
}
family HLT "1111 0100" named "HLT" {
  STOPPED <- 1
}
family CMC "1111 0101" named "CMC" {
  incoming = flag CF
  apply CARRY(not(incoming))
}
family CLC "1111 1000" named "CLC" {
  apply CARRY(0)
}
family STC "1111 1001" named "STC" {
  apply CARRY(1)
}
family CLD "1111 1100" named "CLD" {
  apply DIRECTION(0)
}
family STD "1111 1101" named "STD" {
  apply DIRECTION(1)
}
family CLI "1111 1010" named "CLI" {
  apply INTERRUPTENABLE(0)
}
family STI "1111 1011" named "STI" {
  enabled = flag IF
  when not(enabled) {
    defer intr
  }
  apply INTERRUPTENABLE(1)
}
```

## Port input and output

The independent sixteen-bit port address space uses `1110 r 1 d w`:
`r=0/1` selects a zero-extended immediate byte or DX, `d=0/1` selects input
or output, and `w=0/1` selects AL or AX. Capture the port before the operand.
Word transfers access the low byte first, then port plus one with sixteen-bit
wrapping. Input commits the accumulator only after all reads succeed; byte
input preserves live AH after the device callback. Output captures the whole
accumulator before the first callback. Neither direction changes flags.

```cpu
source immediatePort "zero-extended immediate port": 16 {
  byte = fetch
  return extend(byte, 16)
}
source dxPort "DX port": 16 {
  selector = register DX
  return selector
}
```

The paired encodings share a body through their port source. Explicit byte
accesses keep partial word failures and device ordering visible.

```cpu
family IN8 {
  encoding "1110 0 1 0 0" with portSource = immediatePort named "IN AL,n"
  encoding "1110 1 1 0 0" with portSource = dxPort named "IN AL,DX"
  selector = source portSource
  low = port(selector)
  perform setAL(low)
}

family OUT8 {
  encoding "1110 0 1 1 0" with portSource = immediatePort named "OUT n,AL"
  encoding "1110 1 1 1 0" with portSource = dxPort named "OUT DX,AL"
  selector = source portSource
  contents = source AL
  port(selector) <- contents
}

family IN16 {
  encoding "1110 0 1 0 1" with portSource = immediatePort named "IN AX,n"
  encoding "1110 1 1 0 1" with portSource = dxPort named "IN AX,DX"
  selector = source portSource
  low = port(selector)
  high = port(add(selector, u16(1)))
  AX <- concat(high, low)
}

family OUT16 {
  encoding "1110 0 1 1 1" with portSource = immediatePort named "OUT n,AX"
  encoding "1110 1 1 1 1" with portSource = dxPort named "OUT DX,AX"
  selector = source portSource
  contents = register AX
  port(selector) <- lowByte(contents)
  port(add(selector, u16(1))) <- highByte(contents)
}
```

## String elements and repetition

`1010 ooo w` selects MOVS (`ooo=010`), CMPS (`011`), STOS (`101`),
LODS (`110`), or SCAS (`111`); `w=0/1` means byte/word. Each instruction
invocation handles **one element**, preserving an interrupt boundary between
repeated elements. The prefix scanner supplies `repeatMode=0` for no repeat,
`1` for F3 (REP/REPE), and `2` for F2 (REPNE), plus the original prefix-start
IP and a captured segment override. REPNE is supported only for CMPS/SCAS.

A plain operation never reads CX. A repeated operation reads CX first and
skips every operand, flag, and index effect if it is zero. Nonempty operations
capture source segment/SI and fixed destination ES/DI before any data access,
even if the selected operation uses only one side. This retains the declared
model's observable access schedule. Word reads/writes use the same low-first,
offset-wrapping memory rules as other instructions.

```cpu
codes stringWidths: 8 {
  0 "B" = 0
  1 "W" = 1
}
source stringCount "plain operation or remaining repeat count" (repeatMode: 8): 16 {
  count = match repeatMode: 16 {
    case "00000000" {
      return u16(1)
    }
    case "00000001" {
      count = register CX
      return count
    }
    case "00000010" {
      count = register CX
      return count
    }
    otherwise unsupported
  }
  return count
}
source stringRead "byte or word string operand" (pointer: 32, width: 8): 16 {
  contents = match width: 16 {
    case "00000000" {
      byte = source memory8(pointer)
      return extend(byte, 16)
    }
    case "00000001" {
      word = source memory16(pointer)
      return word
    }
    otherwise unsupported
  }
  return contents
}
action stringWrite "store byte or word string operand" (pointer: 32, width: 8, contents: 16) using memory {
  match width {
    case "00000000" {
      perform store8(pointer, lowByte(contents))
    }
    case "00000001" {
      perform store16(pointer, contents)
    }
    otherwise unsupported
  }
}
source stringAccumulator "AL or AX string operand" (width: 8): 16 {
  contents = match width: 16 {
    case "00000000" {
      byte = source AL
      return extend(byte, 16)
    }
    case "00000001" {
      word = register AX
      return word
    }
    otherwise unsupported
  }
  return contents
}
action loadStringAccumulator "load AL or AX from a captured string operand" (width: 8, contents: 16) {
  match width {
    case "00000000" {
      perform setAL(lowByte(contents))
    }
    case "00000001" {
      AX <- contents
    }
    otherwise unsupported
  }
}
action compareStringOperands "subtraction flags without operand writeback" (width: 8, left: 16, right: 16) {
  match width {
    case "00000000" {
      result = subtract(lowByte(left), lowByte(right))
      apply SUB8FLAGS(lowByte(left), lowByte(right), result, 0)
    }
    case "00000001" {
      result = subtract(left, right)
      apply SUB16FLAGS(left, right, result, 0)
    }
    otherwise unsupported
  }
}
```

After data and comparison flags, read live DF to select the signed byte/word
stride. Advance live SI before DI when both apply. Repeated forms then decrement
live CX and reread it; only a nonzero count tests the new ZF for CMPS/SCAS.
A continuing operation rewinds IP to the supplied prefix start. The next step
refetches prefixes, so code changes, snapshot resumption, and interrupt offers
remain observable. The finishing action's numeric selectors describe which
indices and repeat condition the calling family uses.

```cpu
action finishString "advance live indices and decide repetition" (width: 8, useSI: 8, useDI: 8, compares: 8, repeatMode: 8, startIP: 16) {
  backward = flag DF
  size = add(extend(width, 16), u16(1))
  delta = select(backward, subtract(u16(0), size), size)
  when not(zero(useSI)) {
    position = register SI
    SI <- add(position, delta)
  }
  when not(zero(useDI)) {
    position = register DI
    DI <- add(position, delta)
  }
  when not(zero(repeatMode)) {
    count = register CX
    CX <- subtract(count, u16(1))
    remaining = register CX
    when not(zero(remaining)) {
      when zero(compares) {
        IP <- startIP
      }
      when not(zero(compares)) {
        equal = flag ZF
        when xor(equal, zero(xor(repeatMode, u8(2)))) {
          IP <- startIP
        }
      }
    }
  }
}
```

MOVS captures the complete source before writing the destination. CMPS reads
source before destination; STOS captures AL/AX; LODS preserves live AH for
byte loads; SCAS captures AL/AX before reading the destination. CMPS and SCAS
apply the same subtraction flags as ordinary SUB, without writing either
operand. Each family keeps these effects between the common count guard and
index/repeat action.

```cpu
family stringMove (overridden: 8, segmentOverride: 16, repeatMode: 8, startIP: 16) "1010 010 w" for w in stringWidths named "MOVS{w}" {
  reject "opcode" if zero(xor(repeatMode, u8(2)))
  count = source stringCount(repeatMode)

    sourceSegment = source dataSegment(overridden, segmentOverride)

  }
}

family stringCompare (overridden: 8, segmentOverride: 16, repeatMode: 8, startIP: 16) "1010 011 w" for w in stringWidths named "CMPS{w}" {
```

## Interrupt instructions and shared entry

The four software forms use `1100 11 tt`: INT3 (`tt=00`), INT with a fetched
type byte (`01`), INTO (`10`), and IRET (`11`). INTO tests OF first and has no
other effects when it is clear. Each delivered interrupt captures all four
vector bytes at physical `type * 4` **before** touching flags or the stack,
including when vector and stack overlap.

The entry action captures FLAGS, clears TF then IF and the recognition/wait/halt
latches, and pushes FLAGS, live CS, and live IP in that order. It commits target
CS then IP after the complete frame succeeds. Failed accesses retain completed
effects. The native boundary uses the same action for external interrupts,
traps, and divide errors; its acceptance and reporting policy still remains
outside this chapter. `report interrupt` records completed software delivery
only; it performs no vector or stack effects itself.

```cpu
policy ENTRYFLAGS "disable traps and mask INTR" () {
  TF = 0
  IF = 0
}
action enterInterrupt "interrupt entry" (vector: 8) using memory {
  offset = shiftBits(extend(vector, 16), left, 2)
  targetIP = source memory16(concat(u16(0), offset))
  targetCS = source memory16(concat(u16(0), add(offset, u16(2))))
  savedFlags = source FLAGS
  apply ENTRYFLAGS()
  RECOGNITIONDEFERRED <- 0
  INTRDEFERRED <- 0
  WAITING <- 0
  STOPPED <- 0
  perform pushWord(savedFlags)
  savedCS = register CS
  perform pushWord(savedCS)
  savedIP = register IP
  perform pushWord(savedIP)
  CS <- targetCS
  IP <- targetIP
}
family INT3 "1100 1100" named "INT3" {
  perform enterInterrupt(u8(3))
  report interrupt(u8(3))
}
family INT "1100 1101" named "INT n" {
  vector = fetch
  perform enterInterrupt(vector)
  report interrupt(vector)
}
family INTO "1100 1110" named "INTO" {
  overflow = flag OF
  when overflow {
    perform enterInterrupt(u8(4))
    report interrupt(u8(4))
  }
}
family IRET "1100 1111" named "IRET" {
  perform returnFar(u16(0))
  perform restoreStackFlags()
}
```

IRET completes the ordinary far return before the separate FLAGS pop. Failed
FLAGS reads retain restored IP/CS and completed SP changes. The shared FLAGS
action requests INTR delay on a zero-to-one IF transition before replacing
flags. The native retirement boundary still samples the instruction's original
TF, so restoring flags cannot retroactively create or cancel that owed trap.

## WAIT and coprocessor escape

WAIT (`1001 1011`) samples the physical TEST level once, then writes WAITING.
A high level means busy: initial execution backs IP up to the WAIT opcode,
after any prefixes. A busy continuation leaves IP alone and does not refetch.
A low level releases waiting; continuation advances live IP past WAIT and
requests all-interrupt recognition delay. Initial release leaves IP alone.
Failed sampling writes no CPU state. The boundary records the sample and owns
waiting records, reentrancy, and pending trap handling.

```cpu
action pollWait "sample TEST for initial WAIT or continuation" (resuming: 8) using boundary {
  high = sample test
  WAITING <- high
  when zero(resuming) {
    when high {
      position = register IP
      IP <- subtract(position, u16(1))
    }
  }
  when not(zero(resuming)) {
    when not(high) {
      position = register IP
      IP <- add(position, u16(1))
    }
  }
  when not(high) {
    defer all
  }
}
family WAIT "1001 1011" named "WAIT" {
  perform pollWait(u8(0))
}
```

ESC uses `1101 1 ooo` and ModR/M `mm ppp rrr`; `ooo:ppp` forms the
six-bit coprocessor opcode. Register forms send the selector without reading
CPU registers. Memory forms resolve the ordinary segmented address and read
a complete dummy word even if no coprocessor is connected. Only then do they
send the captured segment, offset, physical address, and word. The device
adapter detaches requests and records only successful delivery. ESC itself
leaves CPU state and flags unchanged; no coprocessor arithmetic is emulated.

```cpu
codes escapes: 8 {
  000 "0" = 0
  001 "1" = 1
  010 "2" = 2
  011 "3" = 3
  100 "4" = 4
  101 "5" = 5
  110 "6" = 6
  111 "7" = 7
}
action escapeMemory "capture dummy word before ESC delivery" (opcode: 8, postbyte: 8, pointer: 32) using memory, boundary {
  segment = truncate(shiftBits(pointer, right, 16), 16)
  offset = truncate(pointer, 16)
  contents = source memory16(pointer)
  send escape(opcode, postbyte) with memory(segment, offset, projectAddress(segment, offset, 4, 20), contents)
}
family ESC (overridden: 8, segmentOverride: 16) "1101 1 ooo" for o in escapes named "ESC {o}" {
  postbyte = fetch
  highOpcode = operand o
  opcode = or(shiftBits(highOpcode, left, 3), and(shiftBits(postbyte, right, 3), u8(7)))
  match postbyte {
    case "11 xxx xxx" {
      send escape(opcode, postbyte)
    }
    case "0x xxx xxx" {
      pointer = source effectiveAddress(postbyte, overridden, segmentOverride)
      perform escapeMemory(opcode, postbyte, pointer)
    }
    case "10 xxx xxx" {
      pointer = source effectiveAddress(postbyte, overridden, segmentOverride)
      perform escapeMemory(opcode, postbyte, pointer)
    }
    otherwise unsupported
  }
}
```
